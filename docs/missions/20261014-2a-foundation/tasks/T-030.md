## Objective

1. `python3 scripts/ledger.py fold <mission>`: appends every `.tasks/ledger/*.json` row whose
   `mission` equals `<mission>` and whose `run_id` is not yet in `docs/missions/ledger.jsonl`, in
   `run_id` order, one canonical JSON line each; then appends the mission's
   `.tasks/drift/<slug>.jsonl` events not yet in `<mission>/drift.jsonl` (an event's id is the
   sha256 of its canonical line). Each row is validated before it is appended. Prints
   `folded rows=<n> drift=<m>`. A second run prints `rows=0 drift=0` and changes nothing.
2. The fold edits only those two files; it does not commit (the orchestrator stages them in
   its acceptance commit).
3. Integration test (temporary repo, real wrappers, fake provider): a worker run writes a row;
   the next launch's clean-tree check still passes; `verify-mission.sh --run-id` passes; `fold`
   then `git add docs/missions && git commit` (the acceptance commit); a second `fold` adds
   nothing and `git status --porcelain` stays empty.
