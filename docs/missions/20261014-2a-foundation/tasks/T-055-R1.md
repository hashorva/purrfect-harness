## Required Changes

### 1. Reuse `model_id()` for `self_reported_model.value` and tighten `text()` and `schemas/worker-output.schema.json`

- In `scripts/observe_output.py`, **reuse the existing `model_id(value)` validator and `MODEL_ID_RE`** (added by `T-054-R1`; do **not** duplicate regexes or add a second model-id validator).
- In `observe_self_reported()`, validate `model.get("value")` with `model_id(model.get("value"))`. If `model_id(...)` returns `None` (including whitespace-only `"   "`, leading/trailing whitespace `" composer-2.5 "`, newlines, control characters `\u0000`, secret-bearing strings like `"gpt-5\nsk-123456789012345678901234\u0000"`, or strings over 80 chars), return `unknown()`.
- In `text(value)` in `scripts/observe_output.py`, reject whitespace-only strings, newlines, and ASCII control characters:
  ```python
  def text(value):
      if (
          isinstance(value, str)
          and value.strip()
          and "\n" not in value
          and "\r" not in value
          and not any(ord(ch) < 32 or ord(ch) == 127 for ch in value)
      ):
          return value
      return None
  ```
- In `schemas/worker-output.schema.json`:
  - Add `"pattern": "^[A-Za-z0-9][A-Za-z0-9._:/-]{0,79}$"` to `properties.self_reported_model.properties.value`.
  - Add `"pattern": "^[^\\r\\n\\x00-\\x1f\\x7f]*\\S[^\\r\\n\\x00-\\x1f\\x7f]*$"` to `properties.summary` and `properties.checks.items.properties.name` so whitespace-only, multiline, or control-character strings are rejected by schema validation.

### 2. Validate only the FINAL top-level JSON object in `observe_self_reported()`

- In `scripts/observe_output.py`, remove the `elif len(stream) == 1: final_text = raw.decode("utf-8", errors="replace")` fallback from the `codex` branch of `observe_self_reported()`. For `codex`, `final_text` must come **only** from the last `{"type": "item.completed", "item": {"type": "agent_message", "text": ...}}` event (`final_text = dig(matches[-1], "item", "text") if matches else None`).
- Extract and validate **only the final top-level JSON object** in `final_text`:
  - When scanning `final_text` for `{`:
    - If `re.search(r'["\[:,]\s*\Z', final_text[:start])` matches (i.e. `{` is preceded by a JSON key colon, comma, or open bracket/brace from an enclosing unclosed JSON structure), do not treat it as a top-level object (`return unknown()`).
    - On `decoder.raw_decode(final_text, start)`:
      - If `RecursionError` is raised, `return unknown()`.
      - If `json.JSONDecodeError as exc` is raised, advance `pos = max(start + 1, exc.pos)` (never `pos = start + 1` into a nested object that `raw_decode` already traversed before failing on the unclosed outer object).
      - If decoded `value` is a `dict`, record `(value, end)` and set `pos = end`; if decoded `value` is not a `dict`, set `pos = end`.
  - If no top-level `dict` was decoded, or if `"{" in final_text[last_end:]` (an unclosed `{` appears after the last decoded object), `return unknown()`.
  - Inspect **only** the final decoded `dict` (`candidate, last_end = candidates[-1]`); never loop over earlier candidates in `candidates`.
  - Verify `isinstance(model, dict) and set(model) == {"value", "source"} and model.get("source") == "self_reported"` and `valid = model_id(model.get("value"))`; return `self_reported(valid)` if `valid is not None` else `unknown()`.

### 3. Validate sources and model IDs in `resolve_model_identity()`

- In `scripts/observe_output.py`, validate each of the three inputs strictly with `model_id()` and its required `source`:
  ```python
  def _validated_model(entry, allowed_source):
      if (
          not isinstance(entry, dict)
          or set(entry) != {"value", "source"}
          or entry.get("source") != allowed_source
      ):
          return None
      return model_id(entry.get("value"))
  ```
  - `requested_value = _validated_model(requested_model, "configured")`
  - `observed_value = _validated_model(observed_model, "observed")`
  - `reported_value = _validated_model(self_reported_model, "self_reported")`
