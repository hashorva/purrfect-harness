## Objective

Design: an optional `observation.subagents` object `{"calls": sourcedCount, "tokens": sourcedCount}`. It appears only when the claude stream shows at least one subagent call. Otherwise it is absent, so every existing receipt and literal fixture stays valid and unchanged. It is never set for codex, cursor or agy, which do not report subagents.

1. `scripts/observe_output.py`, in `claude(stream)`:
   - A subagent call is a `tool_use` block named `Task` or `Agent` inside `message.content` of an `assistant` event whose top-level `parent_tool_use_id` is null or absent. Count distinct block `id`s. Nested calls are inside their parent's total and are not counted.
   - `tokens` sums `tool_use_result.totalTokens` from top-level `user` events that answer those calls. Match by a `tool_result` block's `tool_use_id`.
   - `tokens` is `observed` only when every call has exactly one non-negative non-bool int; otherwise it is `unknown`.
   - With zero calls, add no key.
2. `scripts/execution_receipt.py`:
   - Add `OBSERVATION_OPTIONAL_FIELDS = ("subagents",)` and `SUBAGENT_FIELDS = ("calls", "tokens")`.
   - `validate_observation` requires the keys to be `OBSERVATION_FIELDS` plus any subset of the optional ones.
   - It validates `subagents` as an object with exactly `SUBAGENT_FIELDS`, each a sourced count (message prefix `observation.subagents.`).
3. `schemas/execution-receipt.schema.json`: add an `observation.properties.subagents` object with `additionalProperties: false`, `required: ["calls","tokens"]`, and both properties `{"$ref": "#/$defs/sourcedCount"}`. It does not go in `observation.required`.
4. `tests/test-execution-receipt.py`:
   - `schema_drift` compares `observation.properties` with `OBSERVATION_FIELDS + OBSERVATION_OPTIONAL_FIELDS`, and the subagents properties with `SUBAGENT_FIELDS`. `required` is still `OBSERVATION_FIELDS`.
   - Add `test_subagents_block_is_optional_and_validated`: valid with the block; valid without it; rejected for a missing `tokens`, an extra key, a `True` count, and a negative count.
5. New fixture `tests/fixtures/observe/claude-subagent.jsonl`: the six oracle events, one JSON object per line. `tests/test-observe-output.py`: add `test_claude_counts_top_level_subagent_calls_and_tokens`. It checks the fixture gives `calls` 2 and `tokens` 1234 (observed). A copy with one `totalTokens` removed gives `tokens` unknown. Every existing fixture has no `subagents` key.
6. Commit as `feat(receipts): record subagent calls and their tokens from claude stream-json (T-102)`.
