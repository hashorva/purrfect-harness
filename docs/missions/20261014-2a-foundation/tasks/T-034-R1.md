## Objective

Written from the Architect's T-034 review. Read its entry in PROGRESS.md first. In `scripts/validate_verdict.py` (`--after-run`), `tests/test-verdict.py` and `tests/fixtures/verdicts/`:

1. **Source:** extract only from the **final result text**: the `result` of the last top-level envelope, or the whole output when there is no envelope. Never fall back to earlier events or earlier `result`/`text` strings: if the final text has no JSON, refuse (`ERROR: verdict: ...`, exit 1).
2. **"Last JSON object" means the last top-level object.** Scan linearly and continue after the end of each decoded value (`json.JSONDecoder().raw_decode`), so nested objects are never candidates. A bare verdict, prose followed by a verdict, a verdict in a ```json fence, and two top-level objects (in each order) must give the right answer: the last top-level object is validated.
3. **Limits:** refuse output larger than 4 MiB with a clean `ERROR: verdict:` (check the size before reading everything into memory); catch `RecursionError` (and any decoding error) and refuse cleanly; the scan must be linear, so 1 MiB of `{` finishes within a time bound the test asserts (for example 5 seconds).
4. **Tests** (each fails when its fix is removed; prove each group in a **temporary copy** of the validator, never the live tree; one line per group in the PROGRESS entry, naming the mutated line): bare valid task plan and review verdict accepted; prose + verdict; fenced verdict; first-valid/last-invalid refused and first-invalid/last-valid accepted; the fail-open case (an earlier `tool_result` with a valid plan followed by a final result with no JSON) is refused; final text without JSON refused; depth 5000 refused cleanly; 1 MiB of `{` under the time bound; oversize input refused. The mutant "first object instead of last" must fail a test.
5. (Optional, same files) the registry-test misplacement and unchecked `assertRaises` messages are non-blocking and are NOT part of this task.
6. Do not weaken any existing test. Commit as `fix(verdicts): after-run takes the final answer's last top-level object; refuse hostile input`.
