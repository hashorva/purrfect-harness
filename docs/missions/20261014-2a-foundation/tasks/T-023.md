## Objective

Pure function plus CLI; no launcher change yet.

1. `resolve_v2(fleet, seat, registry, inventory) -> {"provider", "door", "model", "effort", "speed", "source"}`:
   - walk the seat's `doors` in order; skip a door whose `billing_class` is not in
     `policy.billing_classes`; skip a `no_zdr` door when `policy.no_zdr` is `forbid`; skip a door
     whose provider's inventory status is not `success`;
   - in the first remaining door, take the newest model of the seat's family that the inventory
     observed for that provider (reuse the existing family ranking); for a `model-name` provider
     build the ID with `encode_model` using the seat effort and `fast = policy.fast and seat speed == "fast"`;
   - a `-fast` model is never chosen unless `policy.fast` is true;
   - if no door yields a model: `{"model": null, "source": "unavailable", ...}`. Never use
     `FALLBACKS` or any guessed ID.
2. CLI `fleet_state.py resolve-v2 --fleet F --seat S --inventory I` prints the result; exit 1
   when unavailable.
3. Tests in `tests/test-fleet-v2.py` with fixture inventories: the first included healthy door
   wins; a credits door first in the list is skipped unless `policy.billing_classes` has
   `credits`; an `api` door likewise; an unhealthy first door falls through; `-fast` never
   chosen with `fast: false` even when it is the newest; an absent family gives `unavailable`.
