## Objective

Keep Codex's `-s workspace-write` file sandbox in `scripts/execute_provider.py`, turn on network access and live web search, and disable Codex's `cua_repl` and `node_repl` screen/browser control MCP servers for every harness run via per-run `-c` configuration overrides:

1. **Per-run `-c` overrides in `scripts/execute_provider.py`**:
   - Define module constant:
     ```python
     CODEX_CONFIG_OVERRIDES = (
         "-c", "sandbox_workspace_write.network_access=true",
         "-c", 'web_search="live"',
         "-c", 'mcp_servers.cua_repl={command="true",enabled=false}',
         "-c", 'mcp_servers.node_repl={command="true",enabled=false}',
     )
     ```
   - Why `{command="true",enabled=false}` is required: in `~/.codex/config.toml`, `cua_repl` is injected by the bundled `unified-computer-use` plugin rather than defined as a table under `[mcp_servers]`. Passing `-c mcp_servers.cua_repl.enabled=false` without `command` fails Codex bootstrap config validation (`invalid transport in mcp_servers.cua_repl`). Specifying `{command="true",enabled=false}` for both `cua_repl` and `node_repl` satisfies Codex's `McpServerConfig` transport validator in any `CODEX_HOME` and forces both servers to `Status: disabled`.
   - In `provider_contract(spec)` under `if provider == "codex":`, keep `-s workspace-write` and place `*CODEX_CONFIG_OVERRIDES` immediately after `"-c", f'model_reasoning_effort="{effort}"'` and before the final `prompt`:
     ```python
     argv.extend(["-C", repo, "-s", "workspace-write", *codex_git_dir, *codex_agents_dir, "-m", model,
                  "-c", f'model_reasoning_effort="{effort}"', *CODEX_CONFIG_OVERRIDES, prompt])
     ```
2. **How to check `codex mcp list` under the overrides (oracle + probe step)**:
   - Run `codex` (with `/opt/homebrew/bin` on `PATH`) passing all `-c <key=value>` pairs from `provider_contract(spec)[0]` followed by `mcp list`:
     `codex -c model_reasoning_effort="medium" -c sandbox_workspace_write.network_access=true -c 'web_search="live"' -c 'mcp_servers.cua_repl={command="true",enabled=false}' -c 'mcp_servers.node_repl={command="true",enabled=false}' mcp list`
   - Parse each non-header line of `codex mcp list` stdout: the first whitespace-delimited column (`line.split()[0]`) is the server `Name` and the second-to-last column (`line.split()[-2]`) is `Status`. Both `cua_repl` and `node_repl` must be present with `Status == "disabled"` (and never `"enabled"`).
