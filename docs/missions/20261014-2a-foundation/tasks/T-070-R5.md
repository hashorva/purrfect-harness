## Objective

A live worker run was marked `scope: fail` with `<protected:~/.claude.json>` because the owner's running Claude application constantly rewrites `~/.claude.json` (updating session counters, caches, tips, and per-project runtime state) while `T-070-R3` hashes `~/.claude.json` as a whole file. Every other protected path from `T-070-R3` (`.git/config`, `.git/info/exclude`, `.git/hooks`, `.git/index-flags/*`, `~/.zshrc`, `~/.zshenv`, `~/.zprofile`, `~/.bash_profile`, `~/.bashrc`, `~/.gitconfig`, `~/.config/git/config`, `~/.ssh`, `~/Library/LaunchAgents`, and the explicit `~/.claude` config allowlist `settings.json`, `settings.local.json`, `CLAUDE.md`, `.mcp.json`, `commands/`, `agents/`, `hooks/`, `skills/`, `projects/*/memory/`) is static configuration or directory tree state not rewritten by a running app and remains unchanged.

1. **Hash only the canonical MCP and hooks configuration inside `~/.claude.json` (`scripts/execution_receipt.py`)**:
   - Remove `".claude.json"` from `HOME_PROTECTED_FILES` so `HOME_PROTECTED_FILES` contains only the 7 static files (`".zshrc"`, `".zshenv"`, `".zprofile"`, `".bash_profile"`, `".bashrc"`, `".gitconfig"`, `".config/git/config"`).
   - Add helper `_claude_json_config_bytes(raw)` in `scripts/execution_receipt.py`:
     - Parse `data = json.loads(raw.decode("utf-8"))`, catching `(UnicodeDecodeError, json.JSONDecodeError)` and returning `None`.
     - If `not isinstance(data, dict)`, return `None`.
     - Extract top-level `mcp_servers = data.get("mcpServers")` (normalizing `None` to `{}`) and top-level `hooks = data.get("hooks")` (normalizing `None` to `{}`).
     - Extract per-project MCP and hooks configuration from `projects_raw = data.get("projects")`:
       - If `projects_raw is None`: `projects = {}`.
       - Else if `isinstance(projects_raw, dict)`: build `projects = {}` by iterating `for proj_path, proj_val in sorted(projects_raw.items()):`. If `not isinstance(proj_val, dict)`, continue; otherwise let `proj_mcp = proj_val.get("mcpServers")` (`{}` if `None`) and `proj_hooks = proj_val.get("hooks")` (`{}` if `None`). When `proj_mcp != {}` or `proj_hooks != {}`, set `projects[proj_path] = {"hooks": proj_hooks, "mcpServers": proj_mcp}` (projects with empty/absent `mcpServers` and `hooks` are omitted so the running Claude app adding or touching a project's runtime counters/history never alters the digest).
       - Else (non-dict `projects_raw`): `projects = projects_raw`.
     - Return `canonical_bytes({"hooks": hooks, "mcpServers": mcp_servers, "projects": projects})`.
   - Add helper `_protected_claude_json(snap, path, label="~/.claude.json")`:
     - If `not path.is_symlink() and not path.is_file()`, return without modifying `snap` (so creating or deleting `~/.claude.json` during a run still changes `snap` key presence).
     - If `path.is_file()`:
       - Read `config_bytes = _claude_json_config_bytes(path.read_bytes())`.
       - If `config_bytes is not None`:
         - If `path.is_symlink()`: compute `link_hash = hashlib.sha256(os.readlink(path).encode("utf-8", "surrogateescape")).hexdigest()` and `cfg_hash = hashlib.sha256(config_bytes).hexdigest()`, set `snap[label] = hashlib.sha256(f"symlink:{link_hash}:claude-json:{cfg_hash}".encode("ascii")).hexdigest()`, and return.
         - Else: set `snap[label] = hashlib.sha256(b"claude-json:" + config_bytes).hexdigest()` and return.
     - Otherwise (the file failed to parse as a JSON object, or is a non-file symlink): fall back to `_protected_file(snap, path, label)` which uses `_protected_digest(path)` (`b"file:" + raw`). Because parsed snapshots use the `claude-json:` prefix and unparsable snapshots use `_protected_digest`'s `file:` prefix, a file that fails to parse matches as a whole only if it was unparsable before AND after with identical bytes; transitioning between parsable and unparsable is always a violation.
   - In `protected_snapshot(repo)`, right after the `for rel in HOME_PROTECTED_FILES:` loop, call `_protected_claude_json(snap, home / ".claude.json")`.
