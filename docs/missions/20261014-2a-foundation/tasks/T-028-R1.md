## Objective

**Why this task exists.** The Architect's review of T-028 passed the privacy rule (380 hostile values in 20 fields were all rejected; legitimate rows pass; nested
fields are covered), but 7 of 16 mutations of the rule survived: its tests would not notice if the `\r` check or any of the `ghp_`, `github_pat_`,

1. Add one negative test per untested pattern in `tests/test-ledger.py`: a row (built from the good fixture) with a hostile value in a text field, for each of:

   `-----BEGIN …-----` block header; a JWT-shaped value (three base64url segments separated by dots). Use obviously fake values with the right shape
   (never a real secret). Each test asserts the rule rejects the row with the message that names the field, and that the rejected value is **not** printed.
2. Each new test must fail when its pattern is removed: prove it once per pattern in a **temporary copy** of `scripts/ledger.py` (never in the live tree) and
   record one line in the PROGRESS entry. Do not weaken or remove any existing test. Change no code.
