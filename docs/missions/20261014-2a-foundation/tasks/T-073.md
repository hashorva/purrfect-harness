## Objective

Centralize `/opt/homebrew/bin` and `/usr/local/bin` `PATH` setup in `scripts/harness-path.sh`, source it from the spawn wrappers, `fleet-doctor.sh`, and test scripts so tests do not need per-command `PATH=/opt/homebrew/bin:...` overrides, and fail `fleet-doctor.sh` at Gate 0 if any of `git`, `python3`, `tmux`, `jq`, or `shellcheck` is missing on that `PATH`.

1. `scripts/harness-path.sh` (new, executable `0755`, `#!/usr/bin/env bash`):
   - Safe when sourced under `set -euo pipefail` even when `PATH` is unset (`unset PATH; set -u`) or empty.
   - Read candidate directories from `${HARNESS_PATH_DIRS-/opt/homebrew/bin:/usr/local/bin}` (defaults to `/opt/homebrew/bin:/usr/local/bin` when `HARNESS_PATH_DIRS` is unset; allows hermetic unit tests in `tests/test-fleet-doctor.py` to isolate synthetic prefix directories from host binaries).
   - If `PATH` already contains any of the candidate directories, deduplicate repeated occurrences of those candidate directories while preserving their first position and leaving all non-candidate `PATH` entries untouched (so `test_repeated_directory_warns` in `tests/test-fleet-doctor.py` and caller-prepended stub directories such as `PATH="$STUBBIN:$PATH"` keep their exact order).
   - For each candidate directory in order (`/opt/homebrew/bin` then `/usr/local/bin` by default) that exists on disk (`[ -d "$_dir" ]`) and is not already present as a `:`-delimited entry in `PATH`, prepend it ahead of the existing `PATH` so `/opt/homebrew/bin` precedes `/usr/local/bin`, export `PATH`, and `unset` all temporary helper variables.
2. `scripts/spawn-worker.sh` and `scripts/spawn-brain.sh`:
   - Right after `export PYTHONDONTWRITEBYTECODE=1`, resolve `_HARNESS_SCRIPT_DIR="$(cd -- "$(dirname -- "${BASH_SOURCE[0]}")" && pwd)"` and source `"$_HARNESS_SCRIPT_DIR/harness-path.sh"` if it exists, else `"$(pwd -P)/scripts/harness-path.sh"` if it exists (so `spawn-worker.sh` also finds `scripts/harness-path.sh` after re-execing from its `SPAWN_WORKER_SNAPSHOT` temp file and in minimal test fixtures), then `unset _HARNESS_SCRIPT_DIR`. Use `# shellcheck source=scripts/harness-path.sh disable=SC1091`.
3. `scripts/fleet-doctor.sh`:

   - Source `"$SCRIPT_DIR/harness-path.sh"` (`# shellcheck source=scripts/harness-path.sh disable=SC1091`).
   - Check `git`, `python3`, `tmux`, `jq`, and `shellcheck` in that order using `command -v "$tool" >/dev/null 2>&1` on the resulting `PATH`.
