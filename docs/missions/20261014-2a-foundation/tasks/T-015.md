   `write_scope entries must not contain empty, dot, or parent segments`. A leading `./` is
   normalised only on the registry prefix. A registry prefix that normalises to the empty string
   (for example `./`) is refused with an explicit error: it would refuse every task.
4. **Close the glob gap.** A pattern hits a prefix when it can match some path under that
   prefix. The prefix is the normalised registry prefix, split into segments without its trailing `/`.
   Walk the prefix segments with the pattern segments in order:
   - a pattern segment containing `**` → hit (fail-closed: it may over-refuse a rare form
     such as `d**`, which is acceptable);
   - no pattern segment left → no hit;
   - `glob_regex(pattern_segment).fullmatch(prefix_segment)` fails → no hit;
   - otherwise continue to the next segment.
   If every prefix segment is matched, it is a hit only when the pattern has at least one more
   segment. This replaces the `startswith` and `__probe__` checks; both cases are covered by it.
5. Docs stay as in attempt 1. Change the skill sentence only if it no longer matches the rule.
