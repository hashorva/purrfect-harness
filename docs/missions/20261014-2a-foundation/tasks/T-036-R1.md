## Objective

1. **Validate every run id up front** as a canonical lowercase UUID (`str(uuid.UUID(run_id)) == run_id`, the same way `execution_spec` does) before any path is built. 2. **Ledger row:** refuse a symlinked or non-regular ledger file (report it as `MISSING <run_id>: ledger row (not a regular file)`, exit 1); never follow a symlink.
3. **Tests with real fixtures:** build the fixture in a temporary directory by writing real spec, receipt, VerificationRecord(s) and ledger row files that the real loaders accept (take them from the repository's own test fixtures or generate them with the same helper functions the other tests use), and do not mock `load_persisted`, `load_receipt`, `load_record` or `validate_row`. Keep the four missing-artifact cases (each exits 1 and names the gap), and add: a run with several gaps lists all of them; an invalid artifact (a receipt whose run id does not match its file name) is reported, not crashed on.
4. **Hostile ids and symlinks:** `../x`, `x/y`, an upper-case UUID, an empty string and a 300-character string each exit 2 with no id echoed and no path read; a symlinked ledger row exits 1.
5. **Read-only:** a before/after listing (names, sizes and mtimes) of the whole fixture tree is identical after a run.
6. **`--all`:** enumerates the mission's receipts (receipts of another mission are skipped; a symlinked receipt file is skipped or refused, say which in the entry), exits 0 on a complete fixture and 1 when one run lacks an artifact.
