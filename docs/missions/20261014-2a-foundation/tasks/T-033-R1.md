## Objective

Written from the code-reviewer's FAIL on T-033. In `scripts/validate_verdict.py` and `tests/test-verdict.py` (plus new fixtures under `tests/fixtures/verdicts/`):

1. **Schema check recurses and checks shapes.** `--check-schema` (and the schema check that runs before any data validation) must: recurse into every schema-valued keyword (`properties` values, `items`, `if`, `then`); allow `additionalProperties` to be only the boolean `false` (or `true`) and refuse any other value; require `enum` to be a non-empty list, `minItems` and `minLength` to be non-negative integers (not booleans), `required` a list of strings, `type` a known type name or list of them, `pattern` a string that compiles. A malformed keyword value is a clean `ERROR: verdict: ...` exit 1, never a traceback.
2. **Data mode refuses an unsupported schema** (same refusal as `--check-schema`) before it validates anything.
3. **Tests assert specific reasons**, not only exit 1: missing field -> `required property is missing`; empty steps and empty evidence -> `at least 1 item`; a string field given an integer -> `expected string` (new fixture); a boolean where an integer is expected is refused; a non-object top-level JSON value is refused; BLOCKED with `blocking_question` present is accepted.
4. **New refusal tests:** an unsupported keyword nested inside `properties`, `items`, `if` and `then`; `additionalProperties` as a schema object; non-list `enum`; boolean `minItems`; a non-compiling `pattern`; each exits 1, prints `ERROR: verdict:`, prints no traceback, and is also refused in data mode. Build these schemas in a temporary directory.
5. Prove each new refusal test fails when its check is removed (a **temporary copy** of the validator, never the live tree; one line per group in the PROGRESS entry).
6. Do not weaken any existing test. Commit as `fix(verdicts): validator never fails open; tests assert specific reasons`.
