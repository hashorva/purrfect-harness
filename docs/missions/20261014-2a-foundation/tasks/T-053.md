## Objective

The harness must discover new model families per seat (vendor + tier) by adding a single line in `harness-registry.json`, with no code change and no schema enum edit.

1. `scripts/harness_registry.py` (GUARD):
   - Add `import os` and `FAMILY_RE = re.compile(r"^[a-z][a-z0-9._-]*$")`.
   - In `validate_registry(data)`, allow `data["seat_specs"][seat]` to be `[provider, family_1, family_2, ...]` (a `list` of length `>= 2` where `spec[0]` is in `providers`, every `f` in `spec[1:]` is a `str` matching `FAMILY_RE.fullmatch(f)`, and `len(set(spec[1:])) == len(spec[1:])`). On failure raise `RegistryError(f"registry.seat_specs.{seat} must be [provider key, non-empty family]")`.
   - In `load_registry(path=None)`, resolve `path = Path(path or os.environ.get("HARNESS_REGISTRY") or REGISTRY_PATH)` so tests and subprocesses can point `HARNESS_REGISTRY` at a temp registry copy.
   - In `legacy_view(registry)`, build `seat_specs = {seat: (names[spec[0]], spec[1]) for seat, spec in registry["seat_specs"].items()}` so 2-tuple callers stay compatible when a seat lists multiple ranked families.
   - Add `seat_families(registry)` returning `{seat: (names[spec[0]], tuple(spec[1:])) for seat, spec in registry["seat_specs"].items()}` (after `validate_registry(registry)`), where `spec[1:]` is ordered from highest-ranked (newest) family to lowest-ranked family.
2. `scripts/fleet_state.py` (GUARD):
   - Import `seat_families` from `harness_registry`.
   - Add token-aware family matching and ranked family selection:
     - `has_family(model, family)`: split both with `model_tokens`; return `True` iff `ft` is non-empty and appears as a contiguous token slice `mt[i:i+len(ft)] == ft` (so `"argon"` matches `gemini-4-argon-high` and never `gemini-4-argonx-high`).
     - `choose_with_family(values, families, allow_fast=False)`: accept a single family `str` or sequence of ranked family strings; iterate `families` in rank order and for the first family with matching candidates `[x for x in values if has_family(x, family) and (allow_fast or not is_fast(x))]`, return `(sorted(choices, key=model_rank, reverse=True)[0], family)`. If none match, return `(None, families[0] if not isinstance(families, str) else families)`.
     - `choose(values, family, allow_fast=False)`: return `choose_with_family(values, family, allow_fast=allow_fast)[0]`.
     - `unlisted_models(values, families)`: accept a family `str` or sequence of family strings; return `[x for x in values if not any(has_family(x, f) for f in families)]`.
   - In `make_seats(providers, last_good)`: load `s_fams = seat_families(load_registry())` and per-provider union `p_fams = {p: tuple(f for prov, fs in s_fams.values() if prov == p for f in fs) for p in PROVIDERS}`. For each `seat, (provider, families)` in `s_fams.items()`, when unavailable set `"family": families[0]` and `"unlisted": []`; otherwise set `model, family = choose_with_family(values, families)` and `unlisted = unlisted_models(values, p_fams[provider])` (if `not model`, set `"model": "unavailable"`, `"family": families[0]`, `"health": "unknown"`, `"source": "unavailable"`, `"unlisted": unlisted`; if matched, include `"family": family` and `"unlisted": unlisted`).
   - In `inventory(out, json_only)`: when `not json_only`, print `Fleet inventory @ {doc['probed_at']}`, then for each `seat, s` in `doc["seats"].items()` with non-empty `s.get("unlisted")` print `f"note: {seat} unlisted: {', '.join(s['unlisted'])}"`, then `Wrote {out}`.
   - In `seat_source_is_truthful(value, current, retained, seat, name, s_fams=None)`: look up `provider, families = (s_fams or seat_families(load_registry()))[seat]` and require `value["provider"] == provider and value["family"] in families`.
   - In `validate_inventory(doc)`: load `s_fams = seat_families(load_registry())`; in the seat loop allow optional `"unlisted"` (`set(value) - {"unlisted"}` must equal `{"provider","model","family","health","source","capabilities"}`, and if `"unlisted"` is present it must be a `list` of non-empty strings `all(isinstance(x, str) and x.strip() for x in value["unlisted"])`), and pass `s_fams` to `seat_source_is_truthful`.
   - In `validate_fleet_v2_seat`: build `families = {(spec[0], f) for spec in registry["seat_specs"].values() for f in spec[1:]}`.
   - In `validate_fleet_v1`: check `v["family"]` against `{f for p, fams in seat_families(load_registry()).values() if p == v["provider"] for f in fams}`.
   - In `resolve_v2(fleet, seat, registry, inventory)`: for each usable door (`provider = door_spec["provider"]`), resolve the seat's ranked family tuple from `registry["seat_specs"]` as `families = tuple(registry["seat_specs"][seat][1:]) if seat in registry["seat_specs"] and registry["seat_specs"][seat][0] == provider else next((tuple(s[1:]) for s in registry["seat_specs"].values() if s[0] == provider and spec["family"] in s[1:]), (spec["family"],))`; call `raw, matched_family = choose_with_family(provider_models(record, key), families, allow_fast=fast)` and pass `matched_family` to `encode_model(registry, provider, base, matched_family, spec["effort"], fast)`.
3. `schemas/fleet-inventory.schema.json` (GUARD):
   - Add `"family": {"type": "string", "pattern": "^[a-z][a-z0-9._-]*$"}` under `"$defs"`.
   - In `"$defs"."seat"`: set `"family": {"$ref": "#/$defs/family"}` and add optional `"unlisted": {"$ref": "#/$defs/models"}` in `"properties"`; remove `"family": {"enum": [...]}` from all four provider `then` objects in `"allOf"` (keep `"capabilities": {"const": ...}` untouched).
