## Objective

Define the worker structured final output schema with `self_reported_model` (source always `"self_reported"`, never `"observed"`) and implement the four model-identity attribution rules in `scripts/observe_output.py`.

1. `schemas/worker-output.schema.json` and `tests/fixtures/verdicts/good-worker-output.json`:
   - Create `schemas/worker-output.schema.json` (JSON Schema draft 2020-12, compatible with `scripts/validate_verdict.py --check-schema`) with `type: "object"`, `additionalProperties: false`, `required: ["self_reported_model", "summary", "checks"]`, and `properties`:
     - `"self_reported_model"`: `{"type": "object", "required": ["value", "source"], "additionalProperties": false, "properties": {"value": {"type": "string", "minLength": 1}, "source": {"enum": ["self_reported"]}}}`
     - `"summary"`: `{"type": "string", "minLength": 1}`
     - `"checks"`: `{"type": "array", "items": {"type": "object", "required": ["name", "exit_code"], "additionalProperties": false, "properties": {"name": {"type": "string", "minLength": 1}, "exit_code": {"type": "integer"}}}}`
   - Create `tests/fixtures/verdicts/good-worker-output.json` matching `schemas/worker-output.schema.json`.
2. `scripts/observe_output.py`:
   - Add `self_reported(value)` returning `{"value": value, "source": "self_reported"}`.
   - Add `observe_self_reported(provider, raw)` which inspects the final assistant/result text of the CLI stream (for `claude` and `cursor`: `last.get("result")` from the last `type == "result"` event; for `agy`: `dig(last, "result", "response")` from the last `event == "result"` event; for `codex`: `dig(last, "item", "text")` from the last `type == "item.completed"` event where `dig(e, "item", "type") == "agent_message"`, or raw text if the stream is a single JSON object). If that final text decodes as (or ends with a fenced/bare JSON object containing) a dict whose `"self_reported_model"` is a dict with `keys == {"value", "source"}`, `source == "self_reported"`, and a non-empty string `value`, return `self_reported(value)`. Otherwise (including when `source` is `"observed"`, `"configured"`, `"estimated"`, `"unknown"`, or `value` is empty/non-string), return `unknown()` (`{"value": None, "source": "unknown"}`). Never return `source == "observed"` from `observe_self_reported`.
   - Add `resolve_model_identity(requested_model, observed_model, self_reported_model)` implementing the four attribution rules without ever merging the columns:
     - Rule 1 (`observed` differs from `requested`): when `observed_model.get("source") == "observed"` and `text(observed_model.get("value"))` is present, the run is attributed to `observed_model["value"]` (`attributed_model = observed_model["value"]`, `attributed_source = "observed"`, `confidence = "high"`, `routing_weight = 1.0`). If `requested_model.get("source") == "configured"` and `text(requested_model.get("value"))` is present and `observed_model["value"] != requested_model["value"]`, set `drift = True` and include `"model_drift"` in `flags`; otherwise `drift = False`.
     - Rule 2 (`observed` is `unknown` and `self_reported` is present): when `observed_model.get("source") == "unknown"` and `self_reported_model.get("source") == "self_reported"` and `text(self_reported_model.get("value"))` is present, use `self_reported_model["value"]` with low confidence (`attributed_model = self_reported_model["value"]`, `attributed_source = "self_reported"`, `confidence = "low"`, `routing_weight = 0.5`, `drift = False`, include `"low_confidence_model"` in `flags`).
     - Rule 3 (both `observed` and `self_reported` are `unknown`): allowed and visible with lower weight in routing data (`attributed_model = text(requested_model.get("value"))`, `attributed_source = requested_model.get("source", "unknown") if text(requested_model.get("value")) else "unknown"`, `confidence = "unknown"`, `routing_weight = 0.25`, `drift = False`, `flags = []`).
     - Rule 4 (`self_reported` differs from `observed`): when both `observed_model` (`source == "observed"`) and `self_reported_model` (`source == "self_reported"`) are present and their `value`s differ, set `self_reported_mismatch = True` and record only (do not add a drift flag or fail; `observed_model["value"]` remains `attributed_model` with `confidence = "high"` and `routing_weight = 1.0`). Otherwise `self_reported_mismatch = False`.
     - Return `{"attributed_model": attributed_model, "attributed_source": attributed_source, "confidence": confidence, "routing_weight": routing_weight, "drift": drift, "self_reported_mismatch": self_reported_mismatch, "flags": flags}`.
3. `tests/test-verdict.py` and `tests/test-observe-output.py`:
   - In `tests/test-verdict.py`: include `"schemas/worker-output.schema.json"` in `test_schema_checks_and_usage_exit` and `test_good_fixtures_pass`, and add `test_worker_output_schema_requires_self_reported_source_and_rejects_observed` proving that `source: "observed"`, `source: "configured"`, empty `value`, and missing `self_reported_model` are all rejected by `scripts/validate_verdict.py`.
   - In `tests/test-observe-output.py`: add `test_observe_self_reported_never_accepts_observed_source` and `test_resolve_model_identity_four_rules` covering all four rules and verifying that the input dicts are never mutated or merged.
4. Commit as `feat(schema,observe): add worker-output self_reported_model schema and attribution rules (T-055)`.
