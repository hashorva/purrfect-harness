   run from a repository root. For each run (with `--all`: every receipt of the mission) print a
   block: run id, seat/provider/model/effort/speed from the spec; spec path and sha256; receipt
   outcome, exit code, commits and observed model with its source; every VerificationRecord

   validation result.
2. Exit 1 if any run lacks any of the four (spec, receipt, at least one record, a valid
   ledger row), after printing all blocks and a final `MISSING <run_id>: <what>` line per gap.
3. New `tests/test-reconstruct.py` (wired into the suite; script and module in the manifest):
   a complete fixture run exits 0; removing each of the four in turn exits 1 and names it.
