# Task: Show the last 60 lines when a check fails (F016 step 1)

Plan tags: category `tests`, size `S`, review `grok` or `argon`.
Feature F016 is added by the Front Desk. GitHub Actions on clean Linux and macOS runners fails several `tests/run-tests.sh` checks that pass locally, and `check` sends the command's output to `/dev/null`, so the log is only `FAIL : <name>`. ## Objective

Replace only the `check` function in `tests/run-tests.sh`. Leave every other line unchanged, including `FAIL=0` above it and the final `if [ "$FAIL" -eq 1 ]` exit. A green local suite must stay green.

1. Keep the opening line exactly `check() { # check <description> <command...>`. The oracle copies from that line through the `}` that brings the `{` / `}` depth back to zero, so braces in the body must balance. `FAIL` stays global. `out` and `line` stay local so they do not leak into the rest of the script.
2. On success, print exactly today's ok line and nothing else (`echo "  ok   : $desc"`). Discard the captured output.
3. On failure, print exactly today's FAIL line (`echo "  FAIL : $desc"`), then the last 60 lines of the command's combined stdout and stderr. Prefix each of those lines with four spaces, a pipe, and a space, using `printf '    | %s\n'`. Then set `FAIL=1`.
4. Keep the function's exit status 0 in both branches under `set -euo pipefail`. A failing command must not abort the suite; the script still ends with `TESTS FAILED` / exit 1 only when `FAIL` is 1. `|| true` on `rm` and on the read loop is required for that.
5. Store the capture with `mktemp -t purrfect-check.XXXXXX` (the same form as `scripts/spawn-worker.sh`; bare `mktemp` is not portable) and `rm -f` it on both branches. Do not create the file inside the worktree.
6. Commit as `fix(tests): show the last 60 lines when a check fails (T-125)`.

Replace the function with exactly:

```bash
check() { # check <description> <command...>
  local desc="$1"; shift
  local out line
  out="$(mktemp -t purrfect-check.XXXXXX)"
  if "$@" >"$out" 2>&1; then
    rm -f "$out" || true
    echo "  ok   : $desc"
  else
    echo "  FAIL : $desc"
    while IFS= read -r line || [ -n "$line" ]; do
      printf '    | %s\n' "$line"
    done < <(tail -n 60 "$out") || true
    rm -f "$out" || true
    FAIL=1
  fi
}
```

## Why each check exists

- The oracle extracts `check` from `tests/run-tests.sh` and runs that text under `set -euo pipefail`. It fails on base because `>/dev/null 2>&1` drops `reason-text`.
