## Objective

After `T-070-R6` (commit `693aa6c`), `SeatSmoke.test_dest_inside_source_is_refused_unless_under_tasks_smoke` fails with `ERROR smoke: untracked Git delta contains a path outside the workspace` when `seat_smoke.py` clones into `.tasks/smoke/run/repo` inside the source repo. Because `.tasks/smoke/run/repo` contains a `.git/` directory, `git ls-files --others -z --` (without `--exclude-standard`) reports the nested Git repository with a trailing slash (`.tasks/smoke/run/repo/`). `nul_paths` then splits on `"/"`, sees a trailing empty segment `""`, and raises `ReceiptError("untracked Git delta contains a path outside the workspace")` before `_is_harness_ignored` can subtract `.tasks/**`; in addition, `_is_harness_ignored` checked `_is_gitignore_path(path)` before `parts[0] == ".tasks"`, which would fail to subtract `.gitignore` files inside `.tasks/**`.

1. **`scripts/execution_receipt.py`**:
   - In `nul_paths(raw, label)`:
     - Normalize a single trailing directory slash emitted by `git ls-files --others` for nested Git repositories before validating path segments:
       ```python
       def nul_paths(raw, label):
           try:
               values = [item.decode("utf-8") for item in raw.split(b"\0") if item]
           except UnicodeDecodeError as exc:
               raise ReceiptError(f"{label} contains a non-UTF-8 path") from exc
           normalized = []
           for value in values:
               clean = value[:-1] if len(value) > 1 and value.endswith("/") else value
               if (not clean or clean.startswith("/") or
                       any(part in {"", ".", ".."} for part in clean.split("/"))):
                   fail(f"{label} contains a path outside the workspace")
               normalized.append(clean)
           return normalized
       ```
     - Note: `"/"`, `"/abs"`, `"a//b"`, `"a//"`, `"./a"`, and `"../a"` must still raise `ReceiptError(f"{label} contains a path outside the workspace")`.
   - In `_is_harness_ignored(path, ignore_lines)`:
     - Normalize `clean_path = path[:-1] if len(path) > 1 and path.endswith("/") else path` and `parts = clean_path.split("/")`.
     - Check `if parts[0] == ".tasks": return True` **first**, before `_is_gitignore_path(clean_path) or _is_stdlib_shadow(clean_path)`, so everything under `.tasks/` (`.tasks/smoke`, `.tasks/probes`, `.tasks/receipts`, `.tasks/specs`, `.tasks/logs`, nested clones, and any files inside them) is unconditionally subtracted as harness state.
     - Keep `if _is_gitignore_path(clean_path) or _is_stdlib_shadow(clean_path): return False` immediately after `parts[0] == ".tasks"` so worker-written `.gitignore` files and stdlib-shadowing modules anywhere outside `.tasks/` remain violations.
     - Keep `"__pycache__" in parts or clean_path.endswith(".pyc") or parts[-1] == ".DS_Store"` and the `ignore_lines` loop matching against `clean_path` and `parts`:
       ```python
       def _is_harness_ignored(path, ignore_lines):
           clean_path = path[:-1] if len(path) > 1 and path.endswith("/") else path
           parts = clean_path.split("/")
           if parts[0] == ".tasks":
               return True
           if _is_gitignore_path(clean_path) or _is_stdlib_shadow(clean_path):
               return False
           if "__pycache__" in parts or clean_path.endswith(".pyc") or parts[-1] == ".DS_Store":
               return True
           for rule in ignore_lines:
               clean = rule.lstrip("/")
               if clean.endswith("/"):
                   prefix = clean.rstrip("/")
                   if prefix and (clean_path == prefix or clean_path.startswith(prefix + "/") or
                                  ("/" not in prefix and not rule.startswith("/") and prefix in parts[:-1])):
                       return True
               elif clean and fnmatch.fnmatchcase(clean_path, clean):
                   return True
           return False
       ```
