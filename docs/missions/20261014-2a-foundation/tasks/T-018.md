## Objective

1. New `scripts/observe_output.py` with one pure function `observe(provider, raw: bytes) -> dict`
   (provider is the canonical registry name: `claude`, `codex`, `cursor`, `agy`; `agent` maps
   to `cursor`) and a CLI `python3 scripts/observe_output.py <provider> <file>` that prints the
   result as canonical JSON. Result shape:
   `{"observed_model": V, "usage": {"input": V, "output": V, "cache": V, "reasoning": V}, "fast_state": V}`
   where every `V` is `{"value": <str|int|null>, "source": "observed"|"unknown"}`.
   `estimated` is reserved for later writers; this parser never estimates.
2. Truth rules: a value is `observed` only when it is read from the CLI's own output; otherwise
   `{"value": null, "source": "unknown"}`. The function has no parameter for the spec, seat or
   requested model, so it cannot copy them. Lines that are not JSON are skipped. Any parse
   error gives all-unknown, never an exception.
   Cursor (`stream-json`): `observed_model` comes only from an init/system event that names the
   model; usage and session fields as the samples show. Claude: `modelUsage` / `usage`.
   Codex and agy: as the samples show; if agy has no JSON mode, agy is all-unknown.
3. Fixtures `tests/fixtures/observe/<provider>.<ext>` copied from the P-2 samples. Replace
   session ids, account ids, emails and any user path with fixed placeholders; keep the
   structure. Add `empty.txt` and `garbage.txt`.
4. New `tests/test-observe-output.py`: the expected result for each fixture; empty and garbage
   give all-unknown for each provider; for each JSON fixture, deleting the model key gives
   `observed_model` unknown; `inspect.signature(observe)` has exactly `(provider, raw)`.
   Wire the test into `tests/run-tests.sh`; add the script to the manifest ownership lists next
   to `scripts/execution_receipt.py`.
