## Objective

1. New `scripts/observe_output.py` with one pure function `observe(provider, raw: bytes) -> dict`
   (provider is the canonical registry name: `claude`, `codex`, `cursor`, `agy`; `agent` maps
   to `cursor`; any other name raises `ValueError`) and a CLI
   `python3 scripts/observe_output.py <provider> <file>` that prints the result as canonical
   JSON (`sort_keys=True`, `separators=(",", ":")`). Result shape:
   `{"observed_model": V, "usage": {"input": V, "output": V, "cache": V, "reasoning": V}, "fast_state": V}`
   where every `V` is `{"value": <str|int|null>, "source": "observed"|"unknown"}`.
   `estimated` is reserved for later writers; this parser never estimates.
2. Truth rules (all providers):
   - A value is `observed` only when it is read from the CLI's own output; otherwise
     `{"value": null, "source": "unknown"}`. The function has no parameter for the spec,
     seat or requested model, so it cannot copy them.
   - The input is a runner log: provider stdout and stderr in one stream, possibly with
     launcher lines before it. Decode as UTF-8 with `errors="replace"`, split into lines,
     and parse each line on its own. Skip a line that is not JSON or not a JSON object.
   - A model or fast value must be a non-empty string; a usage value must be an `int` that
     is not a `bool` and is `>= 0`. Anything else gives `unknown` for that field only.
   - Copy values as the CLI prints them. Do not add or subtract different fields (Claude's
     input excludes cache reads, Codex's input includes them; the parser does not normalize).
     Cache-write counts are not part of the F003 shape and are not recorded.
   - No input ever raises; at worst every field is `unknown`.
3. Field map, from the P-2 samples (exact keys):
   - **claude** (`--output-format json`; one object with `"type": "result"`; if several, use
     the last): `observed_model` = the only key of `modelUsage` when it has exactly one key;
     zero or several keys give `unknown` (no guess about which model did the work).
     `usage.input` = `usage.input_tokens`; `output` = `usage.output_tokens`;
     `cache` = `usage.cache_read_input_tokens`; `reasoning` =
     `usage.output_tokens_details.thinking_tokens`. `fast_state` = `fast_mode_state`.
   - **codex** (`--json` lines): `observed_model` and `fast_state` are always `unknown` (no
     such field exists). Usage comes from every `"type": "turn.completed"` event's `usage`:
     `input` = `input_tokens`, `output` = `output_tokens`, `cache` = `cached_input_tokens`,
     `reasoning` = `reasoning_output_tokens`. With several such events, a field is the sum of
     that same field over all of them, and `unknown` if any of them lacks a valid value.
   - **cursor** (`stream-json` lines): `observed_model` = `model` of the event with
     `"type": "system"` and `"subtype": "init"`, copied as printed (a display name such as
     `Composer 2.5`; do **not** map it to a CLI model id). If several init events disagree,
     `unknown`. Usage from the last `"type": "result"` event's `usage`: `input` =
     `inputTokens`, `output` = `outputTokens`, `cache` = `cacheReadTokens`; `reasoning` and
     `fast_state` are always `unknown`.
   - **agy**: always all-unknown. Its output was never observed, so there is no shape to read.
4. Fixtures in `tests/fixtures/observe/`. Copy the samples byte for byte except these
   replacements: every value of `session_id`, `uuid`, `thread_id` and `request_id` becomes
   `00000000-0000-0000-0000-000000000000`; Cursor's `cwd` becomes `/workspace`. Keep all other
   keys, values and line order.
   - `claude.json` (from `claude.out`), `codex.jsonl` (from `codex.out`), `cursor.jsonl` (from `cursor.out`).
   - `claude-log.txt`: two launcher-style text lines, then the stderr line
     `Warning: no stdin data received in 3s, proceeding without it.`, then the `claude.json` line.
   - `claude-two-models.json`: `claude.json` with a second `modelUsage` key `claude-sonnet-5-5`
     (copy of the first entry's object).
   - `codex-two-turns.jsonl`: `codex.jsonl` with its `turn.completed` line repeated once.
   - `cursor-no-init-model.jsonl`: `cursor.jsonl` with the `model` key removed from the init event.
   - `wrong-types.jsonl`: JSON lines that are valid but wrong: a `result` object whose usage
     values are strings, `true` and `-1` and whose `modelUsage` is a list; a `system`/`init`
     event whose `model` is `5`; a `turn.completed` whose `usage` is `"x"`; a bare `[1, 2]`;
     a bare `"text"`; `null`.
   - `empty.txt` (zero bytes) and `garbage.txt` (non-JSON text and invalid UTF-8 bytes).
5. New `tests/test-observe-output.py`. Expected results are written as literal dicts in the
   test (not computed by the parser):
   - `claude.json` and `claude-log.txt` → model `claude-haiku-5-5`, input 2, output 33,
     cache 19995, reasoning 29, fast `off`, all observed.
   - `codex.jsonl` → input 17685, output 5, cache 12032, reasoning 0 observed; model and fast unknown.
   - `codex-two-turns.jsonl` → input 35370, output 10, cache 24064, reasoning 0.
   - `cursor.jsonl` → model `Composer 2.5`, input 8961, output 23, cache 3878 observed;
     reasoning and fast unknown.
   - `cursor-no-init-model.jsonl` → model unknown, usage as `cursor.jsonl`.
   - `claude-two-models.json` → model unknown, usage and fast as `claude.json`.
   - `agy` gives all-unknown on every fixture; every provider gives all-unknown on
     `wrong-types.jsonl`, `empty.txt` and `garbage.txt`, without an exception.
   - Deleting `modelUsage` from `claude.json` gives model unknown; `agent` gives the same
     result as `cursor`; an unknown provider raises `ValueError`;
     `inspect.signature(observe)` has exactly `(provider, raw)`.
   - The CLI prints the canonical JSON for `cursor.jsonl` and exits 0.
   Wire the test into `tests/run-tests.sh`; add the script to the manifest ownership lists next
   to `scripts/execution_receipt.py`.
