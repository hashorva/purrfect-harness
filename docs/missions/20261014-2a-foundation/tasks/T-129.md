```python
def tree_snapshot(root):
    # The fixture repo turns off gc.auto and maintenance.auto, but git can still
    # create and delete short-lived lock or temp files under .git. Such a path can
    # vanish between rglob listing it and lstat, so it is skipped. A path that
    # vanishes anywhere else is a real change to the fixture and still raises.
    entries = []
    for path in sorted(root.rglob("*")):
        rel = path.relative_to(root)
        try:
            info = path.lstat()
        except FileNotFoundError:
            if rel.parts[0] == ".git":
                continue
            raise
        if stat.S_ISLNK(info.st_mode):
            kind = "symlink"
        elif stat.S_ISREG(info.st_mode):
            kind = "file"
        elif stat.S_ISDIR(info.st_mode):
            kind = "dir"
        else:
            kind = "other"
        entries.append((rel.as_posix(), kind, info.st_size, info.st_mtime_ns))
    return entries
```

Do not exclude `.git` entries by name pattern. Do not catch any other exception. If a snapshot equality still fails because a `.git` lock exists in only one snapshot, stop and report.

#!/usr/bin/env bash

  - `tree_snapshot` skips a `.git` path that vanishes between listing and `lstat`, and keeps every other entry with the right kind (file, dir, symlink).
