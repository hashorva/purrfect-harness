## Objective

- is longer than 200 characters or contains a newline (transcript or prompt text);
- equals or contains the task's prompt prefix `Read docs/missions/` (the launcher prompt);
- matches a secret-like pattern: `sk-[A-Za-z0-9_-]{20,}`, `ghp_[A-Za-z0-9]{20,}`,
  `github_pat_`, `AKIA[0-9A-Z]{16}`, `xox[abpr]-`, `-----BEGIN`, `eyJ[A-Za-z0-9_-]{20,}\.`;
- contains an email address.
Message: `ERROR: ledger: privacy: <field>`. One negative test per rule; the good fixtures pass.
