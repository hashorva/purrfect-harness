# Task: Keep an instant CLI from dropping the tmux server (F016 step 4)

Plan tags: category `tests`, size `S`, review `grok` or `argon`.
T-127 treats an empty `#{pane_dead_status}` as exit 0. CI on ubuntu-latest and macos-latest still fails `bash tests/test-drive-cli.sh` with `no server running on /tmp/tmux-1001/drive-cli-...` immediately after session creation. `scripts/drive-cli.sh` lines 120–122 start the session and set `remain-on-exit` in a later tmux call. A CLI that exits at once closes the only window before that option is set, the server exits, and the unguarded second `set-option` aborts the driver with status 1. A developer Mac often wins that race.

## Why each check exists

- The oracle fails on base `HEAD` because its tmux shim kills the server after the current `new-session` line, which does not set `remain-on-exit`.
