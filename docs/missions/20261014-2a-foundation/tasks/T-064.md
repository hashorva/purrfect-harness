## Objective

`bash tests/run-tests.sh` fails intermittently in `"manifest and release truth"` because the repository has grown past git's `gc.auto` threshold: `git commit` in `RELEASE_FIXTURE` spawns a background `git gc --auto` that removes loose objects while `cp -R "$RELEASE_FIXTURE/." "$UNTAGGED_FIXTURE"` copies the fixture, causing `cp: .../.git/objects/NN: No such file or directory` and exit 1.

1. `tests/run-tests.sh`: right after `git -C "$RELEASE_FIXTURE" init -q` (before its first `git commit`), add:
   - `git -C "$RELEASE_FIXTURE" config gc.auto 0`
   - `git -C "$RELEASE_FIXTURE" config maintenance.auto false`
2. `tests/run-tests.sh`: right after `git -C "$UNTAGGED_FIXTURE" init -q` (before its first `git commit`), add:
   - `git -C "$UNTAGGED_FIXTURE" config gc.auto 0`
   - `git -C "$UNTAGGED_FIXTURE" config maintenance.auto false`
3. Commit as `fix(tests): disable auto gc and maintenance in release fixtures (T-064)`.
