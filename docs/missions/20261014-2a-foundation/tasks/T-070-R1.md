1. **Permission mode trade-off and workspace confinement (`scripts/execute_provider.py`, `scripts/execution_receipt.py`)**:
   - **CLI trade-off**: `claude --help` offers `--permission-mode` choices `("acceptEdits", "auto", "bypassPermissions", "manual", "dontAsk", "plan")`, `--permission-prompts ("host", "none")`, and `--restricted`. In headless `-p` mode, `acceptEdits` and `dontAsk` deny or prompt on any non-edit tool (`Bash`, `WebSearch`, `WebFetch`, subagents, skills, task tools) unless every internal tool name is enumerated in `--allowedTools` (which `claude --help` does not enumerate), and once `Bash` is allowed in `--allowedTools`, `acceptEdits`/`dontAsk` cannot confine shell writes anyway.      2. a pre/post SHA-256 protected-path snapshot check in `scripts/execution_receipt.py` that catches any modification, creation, or deletion in those paths (including via `Bash`) and fails the receipt's scope check (`scope.result = "fail"`).
