## Why each check exists

- **The oracle** fails on base `HEAD` because the AST walk finds the positional `run_ids` inside a mutually exclusive group. It passes only when all of the following hold:
  - No positional or `nargs="*"` argument is added to a mutually exclusive group, and `run_ids` is still a `nargs="*"` positional.
  - `main(["--help"])` builds its parser under a patched `argparse._MutuallyExclusiveGroup._add_action` that applies Python 3.12's rule deterministically on any local Python, and the help shows `run_ids` and `--all`.
  - `reconstruct_run.py m r1 --all` exits 2 with exactly `ERROR: reconstruct: run ids and --all cannot be combined`, and `reconstruct_run.py m` exits 2 without a traceback.
  - `ci.yml` installs tmux and jq on Linux (apt-get) and macOS (brew), and installs and imports jsonschema, all before `bash tests/run-tests.sh`.
  - Both fleet test files, run with `jsonschema` blocked in `sys.modules`, exit non-zero and print `jsonschema required for this test` with no traceback, and neither contains the SKIP branch.
  - The PATH-helper check resolves `command -v python3` before `unset PATH`, never calls bare `python3 -c` after it, and still passes when its `bash -c` body is run.
- **The three new reconstruct tests** pin the CLI contract: run ids plus `--all` exits 2 and changes nothing, no selection exits 2, and the parser works under 3.12 group rules. The two existing tests guard the run-id and `--all` paths you touched.
- **The fleet tests** prove that, with jsonschema installed, nothing changed.
- **shellcheck, the full suite, clean tree, no `__pycache__`:** standing checks.
