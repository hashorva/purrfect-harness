## Objective

Written from the Architect's T-030 review. Read its entry in PROGRESS.md first. Changes in `scripts/ledger.py` (fold) and `tests/test-ledger.py`:

1. **Key rows on `row["run_id"]`, not the file name.** Refuse a row whose file stem differs from its `run_id`. Refuse a `run_id` already in `docs/missions/ledger.jsonl` or earlier in the same batch, unless its canonical line is byte-identical (then skip it silently, counts 0). Dedupe drift events inside the batch too.
2. **Validate each drift event before append.** It must be an object with exactly the keys `drift()` in `scripts/fleet_state.py` writes (`at`, `mission`, `seat`, `from`, `to`, `inventory_sha256`); `from` and `to` are objects with the resolution keys (read `drift()` and the resolution shape); `inventory_sha256` is 64 lowercase hex; every string goes through the ledger's existing free-text privacy check. Refusals name the field, never the value.
3. A non-object row or drift line, and a committed `ledger.jsonl` line without `run_id`, raise `LedgerError` (exit 1, no traceback).
4. Read only regular, non-symlink files from `.tasks/ledger/` with a size cap (a FIFO must not hang the fold, a symlink is refused, a huge file is refused); refuse a symlinked target file; name an offending file in errors only when its stem is UUID-shaped.
5. **Tests** (temporary repos only), each failing when its fix is removed (prove each group in a **temporary copy** of `scripts/ledger.py`, never the live tree, one line per group in the PROGRESS entry):
   a. fold, add a new row and a new drift event, fold again: old lines byte-identical, new ones appended (catches `"w"` instead of `"a"`);
   b. another mission's drift event is skipped;
   c. each written row equals `canonical_row_line`;
   d. same `run_id` in two files; stem mismatch; a renamed row does not append again on a second fold;
   e. a drift event with a secret-shaped `to.model` (built at run time from fragments), an unknown key, and an absolute path: refused, and the value appears in neither stdout nor stderr;
   f. a non-object row, a non-object drift line, a committed line without `run_id`: `LedgerError`, exit 1, no traceback;
   g. FIFO, symlink and oversize files in `.tasks/ledger/`.
6. Do not weaken any existing test. Commit as `fix(ledger): fold once per run_id, validate drift events, harden file reads`.
