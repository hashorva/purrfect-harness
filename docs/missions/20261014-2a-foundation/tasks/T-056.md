1. `schemas/ledger-row.schema.json` and `scripts/ledger.py`:
   - In `schemas/ledger-row.schema.json`: add `"self_reported_model"` to `required` and `properties` right after `"observed_model"`, referencing `"#/$defs/selfReportedTextFlag"`. Define `"selfReportedTextFlag"` in `$defs` identical to `"textFlag"` except `"source": {"enum": ["self_reported", "unknown"]}` (never `"observed"`, `"configured"`, or `"estimated"`).
   - In `scripts/ledger.py`:
     - Add `SELF_REPORTED_SOURCES = ("self_reported", "unknown")` and `self_reported_text_flag(path, value)` which checks `("value", "source")`, requires `value["source"] in SELF_REPORTED_SOURCES` (failing with `"must be one of self_reported, unknown"`), requires `value["value"] is None` when `source == "unknown"`, and requires `check_text` when `source == "self_reported"`.
     - Add `"self_reported_model"` to `FIELDS` right after `"observed_model"` and register `"self_reported_model": self_reported_text_flag` in `CHECKS`.
     - Never allow `"self_reported"` as a `source` on `observed_model`, `requested_model`, `resolved_model`, or any other flag field.
2. `scripts/execution_runner.py`:
   - Import `observe_self_reported` and `resolve_model_identity` from `observe_output`.
   - In `build_ledger_row(spec, receipt, *, tier, self_reported_model=None)`:
     - Keep all four identity columns separate and never merged: `pool` (vendor), `requested_model` (source `"configured"` or `"unknown"`), `observed_model` (from `receipt["observation"]["observed_model"]`, source `"observed"` or `"unknown"`), and `self_reported_model` (from `self_reported_model` or `receipt.get("self_reported_model")` if valid, defaulting to `{"value": None, "source": "unknown"}`, source `"self_reported"` or `"unknown"`).
     - Call `identity = resolve_model_identity(requested_model_flag, observed_model_flag, self_reported_model_flag)`.
     - Use `attributed_model = identity["attributed_model"] or resolved_model` when calling `registry_door_pool_and_billing(doors, spec["provider"], attributed_model)` so that when `observed_model` differs from `requested_model` (or when `observed_model` is `unknown` and `self_reported_model` is present and `resolved_model` is `unknown`), the run's door/pool/billing attribution follows the attributed model, while if the attributed model does not match a known door for `agent`/`cursor`, it falls back to `resolved_model`'s door so a drifted or unmapped model name never turns a known provider door into `"unknown"` unless `resolved_model` also has no door.
     - Set `"anti_gaming_flags": list(identity["flags"])` (recording `"model_drift"` when `observed_model` differs from `requested_model`, and `"low_confidence_model"` when `observed_model` is `unknown` and `self_reported_model` is used; recording nothing in `anti_gaming_flags` when `self_reported_model` merely differs from `observed_model` or when both are `unknown`).
   - In `run(args)`: extract `self_reported_model = observe_self_reported(observe_provider, raw_output)` (defaulting to `unknown_text()` on exception) and pass `self_reported_model=self_reported_model` to `write_ledger_row` -> `build_ledger_row`.
3. `tests/fixtures/ledger/*.json`, `tests/test-ledger.py`, and `tests/test-execution-integration.py`:
   - Add `"self_reported_model": {"value": null, "source": "unknown"}` to `tests/fixtures/ledger/good-completed.json`, `tests/fixtures/ledger/good-failed.json`, `tests/fixtures/ledger/bad-missing-field.json`, `tests/fixtures/ledger/bad-number-without-source.json`, `tests/fixtures/ledger/bad-observed-null.json`, and `tests/fixtures/ledger/bad-extra-key.json`.

Update `test_every_number_and_model_field_references_a_source_flag` and `test_configured_source_is_allowed_only_on_frozen_configuration_fields` to check that `self_reported_model` references `#/$defs/selfReportedTextFlag` and accepts only `"self_reported"` and `"unknown"` (refusing `"observed"`, `"configured"`, `"estimated"`). Add `test_four_model_columns_never_merge_and_attribution_rules_apply` in `LedgerBuilderTests` verifying all four rules on `build_ledger_row`.
