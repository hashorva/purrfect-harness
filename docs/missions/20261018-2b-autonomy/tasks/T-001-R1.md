## Objective

`python3 scripts/planning_stats.py <routing-data.jsonl>` prints the median total tokens of planning runs per seat and model, as a tab-separated table. Never guess a count.

1. Create `scripts/planning_stats.py` (standard library only). Define `PlanningStatsError(Exception)`, `median(values)`, `summarize(path)` and `main(argv=None)`, and call `sys.exit(main())` under `if __name__ == "__main__"`. The file must not contain the text `20261014-2a-foundation` and must not parse run ids or contain a UUID-shaped pattern (`tests/test-run-id.py` scans every file under `scripts/`).
2. `summarize(path)` reads the file as UTF-8, one JSON value per line. A line that is not JSON raises `PlanningStatsError` with `line <n>: not JSON`. Only JSON objects whose `type` is exactly `architect-run` count; skip every other row.
3. Check for duplicates first. An exact duplicate row (same `json.dumps(row, sort_keys=True)`) counts once; count each later copy as a duplicate and do nothing else with it. It is never also counted as unmeasured.
4. A run's total is `input_tokens + output_tokens + cache_read_tokens`. Do not add `thinking_tokens` or anything in `subagent_stats`. A row that lacks one of the three keys, or whose three counts are all 0, is unmeasured: count it, and leave it out of every median. A count that is present but is not a non-negative `int` (a `bool` is refused) raises `PlanningStatsError` with `line <n>: <key> must be a non-negative integer`.
5. Group measured runs by `(str(seat), str(model))`, using `unknown` for a missing key, and sort the groups. `median`: sort the values; an odd count gives the middle value; an even count gives `(a + b) // 2` of the two middle values; an empty list gives `None`.
6. Return exactly `{"groups": [{"seat", "model", "runs", "median_total"}, ...], "all": {"runs", "median_total"}, "duplicates": n, "unmeasured": n}`. `all` covers every measured run.
7. `main`: one positional argument, the file path. On `PlanningStatsError`, `OSError` or `UnicodeDecodeError`, print `planning_stats: <reason>` to stderr, print nothing to stdout, and return 2. Otherwise print these lines, fields joined by one tab, and return 0: `seat model runs median_total`; one line per group; `all all <runs> <median, or unknown when None>`; `duplicates <n>`; `unmeasured <n>`.

## Why each check exists

- The oracle fails on base HEAD because `scripts/planning_stats.py` does not exist (the import fails). After the change, it first checks the contract on its own temporary data: duplicates count once, thinking tokens are not added, zero and missing counts are unmeasured, review rows are ignored, an even median takes the floor, the CLI prints the exact table, and bad JSON exits 2. Then it checks the frozen baseline: the bytes are the unmodified `06481fd` blob (size and Git blob hash), it passes the `scripts/ledger.py` email, absolute-path and secret patterns, and it gives the exact figures and CLI table. Last, it checks that neither new file names the live 2A directory and that the manifest lists the tool exactly once in each payload list. The baseline never changes, so the oracle cannot drift the way attempt 1's did.
- The baseline figures were recomputed at planning time from `06481fd`. That file has 41 `architect-run` rows: 3 exact duplicates (one zero-token grok row and two claude acceptance rows), 2 unmeasured zero-token grok rows, and 36 measured runs. The figures differ from the 1,233,224 / 1,816,741 in `features.json` F001. Those were computed at `ed9da02`, one row earlier, before the `2B Gate 0 package` planning row (4,449,769 tokens) was appended in `06481fd`.
- Each `PlanningStatsTests.<method>` command runs one test by file and Class.method; the full file repeats them as a set. `test_frozen_2a_baseline` keeps the baseline figures in the suite, which picks this file up through discovery.
- `harness-manifest.py validate` proves that every manifest-owned path, including the new payload entry, exists.
- shellcheck, the full suite, clean tree, no `__pycache__`: standing checks.
