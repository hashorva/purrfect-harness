## Why each check exists

- **Oracle.** It fails on the base because the fixture is missing. Without running the test, it checks:
  - the required runs, a brain receipt, coverage of providers and contracts, and a pre-T-071 codex receipt;
  - that no fixture file is a log or sits under a `.tasks` directory, and none matches `DENY`;
  - the placeholder in every spec and receipt;
  - that each argv's executable matches its receipt, and each accepted run has its record.
- **`test_committed_2a_evidence_passes_require_workers_audit`** runs the real `verify-mission.sh --require-workers` over the rebuilt evidence. The receipt argv hashes come from the stored preimages, so the audit's own recomputation is a real check of today's adapter.
- **`test_adapter_argv_change_breaks_old_receipts`** proves a single changed flag fails the audit.
- **The ledger test** keeps the ledger rows valid and consistent with the receipts.
- **The grep** confirms the CI step and full history.
- **JSON validation, shellcheck, the full suite, clean tree, no `__pycache__`:** standing checks.
