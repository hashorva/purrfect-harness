# Task: One shared safe-git helper; the temp-directory git users go through it (owner item 6a, part 1)

Plan tags: category `scripts`, size `M`, review `argon` or `grok`. After T-068 (both edit `harness-manifest.json`). No adapter argv change.
Git run inside a temporary directory can start a background `gc` or maintenance job, or run a user hook. Either can leave files behind or block cleanup. Every git subprocess in `scripts/` must pass `-c gc.auto=0 -c maintenance.auto=false -c core.hooksPath=/dev/null`, through one helper. This task adds the helper and its scanner and converts the four scripts that work in temporary directories. T-078 converts the rest and empties the transition list.

## Objective

1. New `scripts/git_safe.py` (stdlib, mode 100644, docstring like `scripts/run_id.py`). It defines `GIT = ("git", "-c", "gc.auto=0", "-c", "maintenance.auto=false", "-c", "core.hooksPath=/dev/null")` and `argv(*args)`, which returns `[*GIT, *args]`.
2. In the four scripts, every git argv becomes `git_safe.argv(...)` with the same arguments. The existing `-c core.hooksPath=/dev/null` in `replay_seeded_defects.py` goes, because the helper adds it. The `SEEDS` strings are text, not argv, and do not change.
3. `harness-manifest.json`: add `scripts/git_safe.py` to `install_payload_paths` and `update_paths`, next to `scripts/run_id.py`.
4. New `tests/test-git-safe.py` (unittest), class `GitSafe`, with two tests:
   - `test_helper_prefix`;
   - `test_no_raw_git_argv_in_scripts`: it parses every `scripts/*.py` except `git_safe.py` with `ast` and fails on any list or tuple literal whose first element is the string `git`. Files in `NOT_YET = {"check-golden-argv.py", "dispatch_policy.py", "execution_receipt.py", "execution_runner.py", "ledger.py", "harness-manifest.py", "execution_spec.py"}` are skipped for now; T-078 converts them.
5. Commit as `feat(scripts): one safe-git helper; temp-directory git calls skip gc, maintenance and hooks (T-077)`.
