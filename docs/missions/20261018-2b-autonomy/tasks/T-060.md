## Objective

`python3 scripts/subagent_audit.py --mission <mission dir> --tasks-dir <dir> --routing <routing-data.jsonl> [--mark-manual]`, run from the repo root, prints a Markdown audit table of a mission's brain runs computed from their saved logs. Only `--mark-manual` writes, and it writes only the routing file.

1. Create `scripts/subagent_audit.py` (stdlib only, at most 110 lines, shebang and docstring like `scripts/run_id.py`, mode 100644). It imports `observe_output` and `run_id` from its own directory. It does not use `subprocess`, a UUID regex or `uuid.UUID(` (`tests/test-run-id.py` scans for them). Do not add it to `harness-manifest.json`: it is a mission evidence tool, not distributed.
   - **Runs.** Every `*.json` in `<tasks-dir>/specs` and `<tasks-dir>/receipts` whose `role` is `brain`, whose `mission` equals `--mission` once trailing `/` are stripped from both, and whose `run_id` passes `run_id.validate_run_id`. Skip files that are unreadable, not JSON or not an object. When a run has both a spec and a receipt, the receipt wins. The record cell is `receipt` or `spec only`; the work unit is `work_unit`; the provider is `provider`.
   - **Per run.** The log is `<tasks-dir>/logs/<run_id>.log`. If it exists, log present is `yes`, and calls and tokens come from `observe_output.observe(provider, log bytes)["subagents"]`; for Claude that is `_claude_subagents` over `observe_output.events`, the same computation the receipt uses. A cell is the value when its source is `observed`, else `unknown`. If `observe` raises `ValueError`, both cells are `unknown`. With no log: `no`, `unknown`, `unknown`.
   - **Routing rows.** Read every line as JSON. If any line is not JSON, exit 2 with `subagent_audit: <path>: line <n>: not JSON` on stderr and nothing on stdout, and leave the file untouched. A `type` `architect-run` row whose `run_id` is missing or empty, or names no audited run, adds a table row:
     - run id cell: `none` when the id is missing, else the id;
     - work unit: the row's `plan`;
     - log present `no`; provider: `seat` up to its first `.`; calls and tokens `unknown`;
     - record: `no run id recorded (ad hoc)` when the id is missing, else `routing row only`.
   - **Confirmed.** A row that has the key `subagent_stats` is confirmed only when its `run_id` names an audited run whose calls cell is an observed number equal to `subagent_stats.spawned`. Every other row with `subagent_stats` is unconfirmed. Rows without `subagent_stats` are never touched.
   - **Output** (stdout, identical with and without `--mark-manual`), in this order:
     - `# Subagent audit: <mission>`, then a blank line;
     - one sentence saying the numbers are computed from saved run logs and that `unknown` means no saved log or no parser, then a blank line;
     - the header `| run id | work unit | log present | provider | Task/Agent calls | subagent tokens | record |` and the separator `|---|---|---|---|---|---|---|`;
     - the audited runs sorted by run id, then the routing-only rows in file order, with a `|` inside a cell written as `\|`;
     - a blank line, then `Unconfirmed routing rows: <n>`.
   - **`--mark-manual`.** Every unconfirmed row that does not already have `"source": "manual"` gets `"source": "manual"` appended as its last key and is re-serialized with `json.dumps(row, separators=(",", ":"))`. Every other line stays byte-for-byte the same. Write through a temporary file in the same directory and `os.replace`; write nothing when nothing changes. Exit 0.
2. `tests/test-subagent-audit.py` (unittest, at most 60 lines). It builds its tree in a temporary directory from inline data plus a copy of `tests/fixtures/observe/claude-subagent.jsonl`, and it never reads `.tasks/` or any mission's `routing-data.jsonl`. It checks:
   - the table cells for a receipt run with a log, a spec-only run without a log, an ad-hoc row and a `routing row only` row;
   - that worker runs and other missions are left out;
   - that confirmed and unrelated rows stay byte-identical under `--mark-manual`;
   - that a second `--mark-manual` run changes nothing, and that without the flag nothing is written;
   - that a `|` in a `plan` is escaped;
   - that a non-JSON line exits 2 and leaves the file untouched.
3. Commit as `feat(metrics): subagent audit table from saved run logs; unconfirmed routing rows marked manual (T-060)`.

## Why each check exists

- The oracle fails on the base (the script does not exist). It passes only when the table is computed from the saved log and the only rows marked `manual` are the unconfirmed ones (ad hoc, no log, count mismatch). It also requires a second run to change nothing and a broken file to be refused untouched. Its data is frozen: inline rows plus a committed observe fixture.
- `test-subagent-audit.py` keeps those properties in the suite; `test-run-id.py` proves the script uses the shared run-id rule.
- shellcheck, the full suite, clean tree, no `__pycache__`: standing checks.
