## Objective

A planning brain run needs effort `high`, a review run needs a seat frozen at `medium`, and a worker needs a seat frozen at `medium`. Each refusal happens before the lock, the log, the ExecutionSpec or any provider process exists.

Scope decisions (binding):
- Planning means the brain actions `mission-init` and `gate0`. They resolve no fleet seat, so the check is on the launch effort that goes into the spec (the default `high` or `--effort`).
- Review and worker checks apply to frozen fleets with `schema_version` 2. A v1 fleet is the 2A format: it stays launchable unchanged, as the 2A evidence and fixtures require.

     - For planning, `effort != "high"` fails with `planning runs need effort high; got <effort>`.
     - Review or worker without `fleet` and `seat` fails with `<role> runs need --fleet and --seat`.
