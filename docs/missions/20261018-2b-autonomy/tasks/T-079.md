## Objective

1. `scripts/verification_record.py`: add `failure_report(index, argv, exit_code, stdout, stderr, lines=20)`, which returns text:
   - first line: `VERIFY FAIL DETAIL: ` followed by `json.dumps({"command": index, "argv": argv, "exit_code": exit_code})`;
   - then the last `lines` lines of stderr followed by stdout, each prefixed `  | `. Output is decoded as UTF-8 with replacement; empty lines are kept, and a trailing newline adds no line.

   In `verify`, each command with a non-zero exit (numbered from 1) prints its report to stderr right after it runs. The record and its validation do not change.
2. `tests/test-verification-record.py`: add `test_failed_command_prints_its_last_output_lines`. A verification whose command writes a known last stderr line and exits 3 must print `VERIFY FAIL DETAIL: {"command": 1` and that line with the `  | ` prefix, and the record must still be `fail`.
3. Commit as `feat(verify): a failed command prints its argv, exit code and last output lines (T-079)`.
