## Objective

A recorded contract's argv never changes. Changing argv means adding contract N+1, with new golden files. T-071 changed codex argv for contracts 2–8, and 76 historic receipts stopped validating (T-115). This test makes that kind of change fail on its own commit.

1. **Fixture spec.** `provider_contract` reads only these fields, so the spec is not a full validated spec. Use:
   - Common fields: `"repo": "/golden/repo"`, `"prompt": "GOLDEN PROMPT"`, `"write_scope": ["scripts/*"]`.
   - Contracts 2–9: `"schema_version": 3` and `"provider_contract_version": N`.
   - Contract 1: `"schema_version": 2` and no `provider_contract_version` key.
   - Provider fields:
     - `codex`: model `gpt-5.5`, effort `high`, speed `unknown`.
     - `claude`: model `golden-claude`, effort `high`, speed `unknown`.
     - `agy`: model `golden-agy-high`, effort `high`, speed `unknown`.
     - `agent` (Cursor): model `golden-agent-high`, effort `high`, speed `standard`.
   - Codex gets a second case, identical except `"write_scope": ["scripts/*", ".agents/skills/*"]`. It exercises contract 5's `.agents` mount.
2. **Historical computation** (scratch only, outside the repo, e.g. under `$TMPDIR`):
   - For a commit C, write `git show C:scripts/execute_provider.py` and `git show C:scripts/execution_spec.py` into a temp directory.
   - Import them there with `PYTHONDONTWRITEBYTECODE=1` and call `provider_contract(spec)` for every case.
   - The window where contract N was current starts at its first commit. Contract 1: the parent of `8298222` (`git rev-parse 8298222^`). Then `2` `8298222`, `3` `210d144`, `4` `865063c`, `5` `0ef0359`, `6` `c598964`, `7` `6991b90`, `8` `1a37351`, `9` `ed1fa71`.
   - Each window runs until the next contract's first commit (exclusive); for contract 9, until `HEAD`. These are exactly the commits in `git log -- scripts/execution_spec.py`.
   - Evaluate every commit in `git log -- scripts/execute_provider.py scripts/execution_spec.py` inside each window. Contract 1 is evaluated at `8298222^` only; the `wip(T-004)` commits are not recorded.
   - Expected result: in every window the output equals the current adapter's output, except for exactly three earlier forms:
     - `claude` v8 at `98d628a`: Claude's argv changed for every contract without a bump; `ed1fa71` restored contracts 1–8.
     - `claude` v9 at `ed1fa71`: the 40-pattern deny-list; `3a57fa7` expanded it without a bump.
     - `codex` v9 at `ed1fa71`: before T-071 added its four `-c` overrides.
   - If git shows anything else, stop and report.
3. **Golden files.** Create `tests/fixtures/golden-argv/<provider>-v<N>.json` for each provider in `codex claude agy agent` and each N in 1–9: 36 files.
   - Each file is one line of canonical JSON (`json.dumps(d, sort_keys=True, separators=(",", ":"), ensure_ascii=False)` plus a newline).
   - Keys:
     - `provider` and `contract` (int).
     - `source_commit`: the full 40-character SHA of the contract's first commit.
     - `source`: `current-differs-from-historical` for claude v9 and codex v9; `historical-equals-current` for all others.
     - `cases`: a list of `{"spec": ..., "argv": ...}`, two cases for codex and one otherwise. `argv` is the current adapter output (by step 2, equal to the historical output except as listed there).
     - `historical`: a list, empty except for the three files above. Each entry is `{"commit": <full SHA of the first commit producing that form>, "argv": <that form for cases[0]>, "accepted_by_adapter": <argv_sha256(argv) in historical_argv_sha256s(cases[0].spec)>}`. Expected values: codex v9 `true`, claude v8 and v9 `false`.
4. **README.** Create `tests/fixtures/golden-argv/README.md` (at most 20 lines) with:
   - The rule: a recorded file is never edited; an argv change adds contract N+1 plus 4 new files and bumps `PROVIDER_CONTRACTS_V3`/`CURRENT_PROVIDER_CONTRACT`.
   - The fixture spec.
   - Which files are historical-equals-current (34) and which differ (claude v9, codex v9).
   - The three historical forms with their commits.
   - The two windows where a contract that was not current drifted temporarily: codex 2–8 in `6ec695c..cccdb43` (T-071/T-115) and claude 1–7 in `98d628a..ed1fa71`.
5. **Test.** Create `tests/test-golden-argv.py`:
   - `class GoldenArgv(unittest.TestCase)` and `unittest.main()` under `if __name__ == "__main__"`.
   - Root via `Path(__file__).resolve().parents[1]`. Insert `scripts/` into `sys.path` and import `execute_provider` and `execution_spec` with `importlib.import_module`.
   - A helper `mismatches(provider_contract)` returns the sorted stems (e.g. `claude-v6`) of files where any case's output differs from its recorded argv.
   - Methods:
     - `test_every_provider_contract_has_one_golden_file`: the files are exactly `PROVIDERS` × ({1} ∪ `PROVIDER_CONTRACTS_V3`); names match content; bytes are canonical; `CURRENT_PROVIDER_CONTRACT == max(PROVIDER_CONTRACTS_V3)`. A new contract without its 4 files fails.
     - `test_adapter_reproduces_every_golden_argv`: `mismatches(execute_provider.provider_contract) == []`. The failure message says: "recorded contract argv changed; add a new contract instead (T-115)".
     - `test_historical_forms_are_documented`: exactly the three historical entries; each differs from its file's current argv; each `accepted_by_adapter` equals `argv_sha256(argv) in historical_argv_sha256s(spec)`.
     - `test_changing_one_old_contract_flag_fails`:
       - Read `scripts/execute_provider.py` and assert `"--allowedTools", "Read,Write,Edit,Bash"` occurs exactly once.
       - Replace it with `"--allowedTools", "Read,Write,Edit"`.
       - Write the result to a `tempfile.TemporaryDirectory()` and load it with `importlib.util.spec_from_file_location("golden_mutant_execute_provider", path)`.
       - Assert `mismatches(mutant.provider_contract) == ["claude-v1", ..., "claude-v8"]` (8 stems).
     - No subprocess and no sleeps.
6. **Wire it in.** In `tests/run-tests.sh`, right after the `ExecutionSpec and provider adapter contracts` check line, add `check "golden provider argv for every recorded contract" python3 tests/test-golden-argv.py`.
7. **Budget and commit.** At most 150 added lines, not counting the 36 one-line fixture files. Commit as `test(adapter): golden argv for every provider contract (T-010)`.

## Why each check exists

- **Oracle.** It fails on the base because the fixture directory is missing. After the change, it checks four things on its own:
  - All 36 files exist, are canonical, and are reproduced by the current adapter.
  - The source commits match each contract's first commit.
  - The contract-1 argv for all four providers equals literals taken from the pre-versioning adapter (`8298222^`), so the fixtures can't simply be regenerated from today's code.
  - The three historical forms are exactly the documented drifts. The pre-T-071 codex form is still accepted; the two Claude forms are not.
- **Each `GoldenArgv.<method>`** runs one property; `test_changing_one_old_contract_flag_fails` is the mutation proof on the real adapter source.
- **JSON validation, shellcheck, the full suite, clean tree, no `__pycache__`:** standing checks.
