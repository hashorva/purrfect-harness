## Objective

`python3 scripts/planning_stats.py <routing-data.jsonl>` prints the median total tokens of planning runs per seat and model, as a tab-separated table. Never guess a count.

1. Create `scripts/planning_stats.py` (standard library only). Define `PlanningStatsError(Exception)`, `median(values)`, `summarize(path)` and `main(argv=None)`, and call `sys.exit(main())` under `if __name__ == "__main__"`.
2. `summarize(path)` reads the file as UTF-8, one JSON value per line. A line that is not JSON raises `PlanningStatsError` with `line <n>: not JSON`. Only JSON objects whose `type` is exactly `architect-run` count; skip every other row.
3. An exact duplicate row (same `json.dumps(row, sort_keys=True)`) counts once. Count the duplicates.
4. A run's total is `input_tokens + output_tokens + cache_read_tokens`. Do not add `thinking_tokens` or anything in `subagent_stats`. A row that lacks one of the three keys, or whose three counts are all 0, is unmeasured: count it, and leave it out of every median. A present count that is not a non-negative `int` (a `bool` is refused) raises `PlanningStatsError` with `line <n>: <key> must be a non-negative integer`.
5. Group measured runs by `(str(seat), str(model))`, with `unknown` for a missing key, and sort the groups. `median`: sort; odd count gives the middle value; even count gives `(a + b) // 2` of the two middle values; empty gives `None`.
6. Return exactly `{"groups": [{"seat", "model", "runs", "median_total"}, ...], "all": {"runs", "median_total"}, "duplicates": n, "unmeasured": n}`. `all` covers every measured run.
7. `main`: one positional argument, the file path. On `PlanningStatsError`, `OSError` or `UnicodeDecodeError`, print `planning_stats: <reason>` to stderr, print nothing to stdout, and return 2. Otherwise print these lines, fields joined by one tab, and return 0: `seat model runs median_total`; one line per group; `all all <runs> <median, or unknown when None>`; `duplicates <n>`; `unmeasured <n>`.
8. Create `tests/fixtures/planning-stats/routing-data.jsonl` with exactly these 8 lines (UTF-8, final newline):
