## Objective

`parse_screen(cli, text)` turns four fixture screens into percent left and reset time. Unparsable text is `unknown`. Never guess. Do not call a CLI.

1. Create `scripts/quota_meter.py` (standard library only). Define `QuotaMeterError` and `parse_screen(cli, text)`. `cli` must be exactly `claude`, `codex`, `cursor-agent`, or `agy`; any other value, including `grok` and `cursor`, raises `QuotaMeterError` before the text is used. Do not import `subprocess`. Do not call `system`, `popen`, or `Popen`.
2. A screen is blocks separated by one blank line. A block is a heading, an optional window line, a percent line, and a reset line, with no other lines and no stripping. The optional window line is exactly `Weekly` (`window` `weekly`) or `5-hour` (`window` `5h`) and overrides the heading default. Headings, pools, and default windows:

   - `claude` / `Current session` / pool `anthropic` / default `5h`
   - `claude` / `Current week (all models)` / pool `anthropic` / default `weekly`
   - `codex` / `5-hour limit` / pool `openai` / default `5h`
   - `codex` / `Weekly limit` / pool `openai` / default `weekly`
   - `cursor-agent` / `Included usage` / pool `cursor` / default `unknown`
   - `agy` / `Gemini 3.8 Flash` / pool `google` / default `unknown`
   - `agy` / `Gemini 4 Argon` / pool `agy-argon` / default `unknown`

   A percent line is exactly `N% used` or `N% left`, N from 0 to 100 with no extra words. `used` stores percent left `100 - N`. `left` stores N. Source is `observed`. A reset line is exactly `Resets ` plus `YYYY-MM-DDTHH:MM:SSZ`. Source is `observed`. The return value is `{"cli": cli, "readings": [ ... ]}` and each reading is `pool`, `window`, `percent_left` `{value, source}`, `reset_at` `{value, source}`. Do not read `harness-registry.json` to fill a missing field.
3. A block that breaks the grammar is one unknown reading: `pool` `unknown`, `window` `unknown`, both flags `{value: null, source: unknown}`. If every block fails, return exactly one unknown reading. Do not turn `resets in 4h53m` into a timestamp. Do not turn a bar of block characters into a percent. `about 65% used` and `101% used` fail the block.
4. Write these UTF-8 files with a final newline and no BOM. The blank line between blocks is empty.
