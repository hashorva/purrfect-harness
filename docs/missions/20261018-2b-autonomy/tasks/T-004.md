## Objective

`python3 scripts/planning_stats.py batch <batch.json> <data.jsonl>` prints six lines: runs, median parent total, median parent-plus-subagent total, median subagent calls and done rate for a named batch of run ids. It exits 2 for a batch of fewer than 10 runs, a duplicate run id, or an unclean run. It never guesses a count. Standard library only. Do not import other harness modules, and do not parse or validate run ids: they are opaque strings, and the F000 scan refuses private run-id parsers.

1. **Batch file**: a JSON object `{"name": <non-empty string>, "run_ids": [<non-empty string>, ...]}`. Anything else raises `PlanningStatsError("batch: must be an object with a name and a list of run ids")`. Checks, in order:
   - fewer than 10 ids raises `batch <name>: <n> runs; a batch needs at least 10`;
   - a repeated id raises `batch <name>: duplicate run id <id>`.
2. **Data file**: UTF-8 JSONL, read as in T-001.
   - A line that is not JSON raises `line <n>: not JSON`.
   - Lines that are not objects are skipped.
   - Exact duplicate rows (same `json.dumps(row, sort_keys=True)`) count once.
   - Two kinds of rows count; every other row is ignored, including routing `review` rows that carry a `run_id`:
     - **Ledger row**: `schema_version == 2` and has `run_id` and `tokens_input`. Its id is `run_id`.
     - **Routing planning row**: `type == "architect-run"`. Its id is `run_id` if present, else `plan:<plan>` when `plan` is a non-empty string, else it has no id.
   - Two different rows with the same named id raise `run <id>: <k> different rows`.
3. **Per run**, for each id in the batch:
   - No row raises `run <id>: not found`.
   - **Parent total**:
     - Ledger: `tokens_input + tokens_output + tokens_cache`, measured only when each has source `observed` and an `int` value ≥ 0 (a `bool` is refused) and the sum is > 0.
     - Routing: T-001's rule (`input_tokens + output_tokens + cache_read_tokens`; missing or all-zero is unmeasured; never add `thinking_tokens`, `tokens_reasoning` or anything in `subagent_stats`).
     - Unmeasured raises `run <id>: unmeasured tokens`.
   - **Clean**:
     - A ledger row whose `outcome` is not `completed` raises `run <id>: no completed receipt (<outcome>)`.
     - A row whose `failure_class` is `environment` raises `run <id>: failure class environment`.
   - **Subagents**:
     - Ledger: `subagents.calls` and `subagents.tokens` count when source is `observed` and the value is an `int` ≥ 0; a missing block or any other source is `None`.
     - Routing: `subagent_stats.spawned` (an `int` ≥ 0) gives the calls; tokens are 0 when spawned is 0, else `None`. A missing or invalid `subagent_stats` gives `None` for both.
   - **Done**: ledger `outcome == "completed"`; routing `outcome == "done"`.
4. **Result**: `batch_summary(batch_path, data_path)` returns exactly `{"batch", "runs", "median_parent_total", "median_parent_plus_subagent_total", "median_subagent_calls", "done"}`.
   - Medians use T-001's `median`.
   - `median_parent_plus_subagent_total` is `None` if any run's subagent tokens are `None`.
   - `median_subagent_calls` is `None` if any run's calls are `None`.
5. **CLI**:
   - In `main`, when the first argument is `batch`, require exactly two more arguments; otherwise print a usage line to stderr and return 2.
   - On `PlanningStatsError`, `OSError` or `UnicodeDecodeError`, print `planning_stats: <reason>` to stderr, print nothing to stdout, and return 2.
   - On success, print these lines, fields joined by one tab, and return 0: `batch <name>`, `runs <n>`, `median_parent_total <n>`, `median_parent_plus_subagent_total <n or unknown>`, `median_subagent_calls <n or unknown>`, `done_rate <done>/<runs>`.
   - The T-001 one-argument mode is unchanged.
6. **Tests**: add to `PlanningStatsTests` in `tests/test-planning-stats.py`. Use temporary files (`tempfile`, cleaned with `addCleanup`) built by one shared helper:
   - `test_batch_reports_medians_and_done_rate`: a mixed ledger and routing batch of 10 gives the exact dict, with `thinking_tokens` and `tokens_reasoning` left out.
   - `test_batch_keeps_unknown_subagent_counts_unknown`: unknown subagent tokens or calls, a ledger row without `subagents`, and a routing row with `spawned` > 0 each give `None` for the affected medians.
   - `test_batch_refuses_small_duplicate_and_unclean_batches`: exit 2 for each of:
     - 9 ids;
     - a duplicate id;
     - an id not found;
     - an id with two different rows;
     - a `failed` ledger row;
     - `failure_class` `environment`;
     - unmeasured tokens;
     - a malformed batch file.
   - `test_batch_cli_prints_the_summary`: the exact six-line stdout and empty stderr.
7. `harness-manifest.json`: add `"scripts/planning_stats.py"` right after `"scripts/ledger.py"` in both `install_payload_paths` and `update_paths`. No copy-set test list needs it, because no script or wrapper imports it.
