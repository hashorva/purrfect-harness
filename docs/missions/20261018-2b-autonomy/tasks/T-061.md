## Objective

1. **`scripts/ledger.py routing-row <ledger-row.json> <category> <size>`** prints one routing-data line computed from one ledger row. It replaces the Front Desk's local `route.py`; the Front Desk appends the output to `routing-data.jsonl`.
   - `category` and `size` must be non-empty one-line text (no control characters), else exit 2 with `ERROR: ledger: ...` on stderr.
   - Read the file and run `validate_row`. On any failure print `ERROR: ledger: <reason>` on stderr and exit 1, with nothing on stdout.
   - On success print `json.dumps(out, separators=(",", ":"))` and exit 0. The keys, in this order:
     - `run_id`, `task`, `category`, `size`;
     - `seat`: `<cli>.<tier>`;
     - `door`;
     - `model`: the `observed_model` value when its source is `observed`, else the `resolved_model` value;
     - `effort`: the `effort` value;
     - `attempt`, `outcome`, `failure_class`;
     - `duration_s`: `round()` of the `wall_time_s` value when observed, else `null`;
     - `input_tokens`, `output_tokens`, `cache_read_tokens`: from `tokens_input`, `tokens_output` and `tokens_cache`, each the value when observed, else `null`;
     - `subagents`: `{"calls", "tokens", "source"}`. Both values and source `observed` only when both ledger `subagents` fields are observed; otherwise both `null` and source `unknown` (a row without `subagents` is unknown);
     - `source`: `"computed"`.
   - Add `routing-row <ledger-row.json> <category> <size>` to the usage line.
2. **`scripts/planning_stats.py`** changes:
   - A row with `"source": "manual"` is skipped as if absent, in `summarize` and in `_index_data_paths` (so in batch and compare too).
   - The legacy `subagent_stats` of an `architect-run` row is no longer read: its subagent calls and tokens are `None` with source `unknown`. Only ledger rows' `subagents` count.
   - The module docstring states both rules. The frozen 2A baseline figures do not change.
3. **Tests.**

Change nothing else in those tests.
   - `tests/test-observe-output.py`: add `import shutil`, a module constant `JQ_SUBAGENTS` and `test_subagents_match_a_jq_one_liner`. The test asserts `shutil.which("jq")` is not None.
