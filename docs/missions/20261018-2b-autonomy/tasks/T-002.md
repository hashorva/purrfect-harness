## Objective

Every receipt observation and every ledger row built from it carries `subagents` = `{"calls": {value, source}, "tokens": {value, source}}`. A claude stream with 2 Agent/Task calls gives calls 2 and the summed tokens (observed). A finished claude stream with no calls gives 0 and 0 (observed). A CLI that reports nothing gives unknown. Old receipts and ledger rows still validate.

- `test-evidence-2a.py` proves every committed 2A receipt still validates.
- JSON validation, shellcheck, the full suite, clean tree and no `__pycache__` are the standing checks.
