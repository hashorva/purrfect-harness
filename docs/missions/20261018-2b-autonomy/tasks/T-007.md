## Objective

1. `scripts/observe_output.py`: move the final-answer selection out of `observe_self_reported` into `final_answer(provider, raw)`, placed directly above it. It returns the final answer text of one CLI run as `str`, or `None`:

3. `required(path)`: read the routing data as UTF-8 JSONL.
   - **Not JSON:** a line that is not JSON raises `ReplayError(f"line {n}: not JSON")`.
   - **Which rows:** only objects whose `type` is `seeded-calibration` count.
   - **Unknown reviewer:** a row's `reviewer` must be a `FAMILY_2A` key, else `ReplayError(f"line {n}: unknown 2A reviewer")`.
   - **Case match:** its `case` must be a `CASES` id with the same `task`, and its `commit` (at least 7 characters) a prefix of that case's commit. Otherwise `ReplayError(f"line {n}: row does not match case {case}")`.
   - **`caught` field:** it must be a `bool`.
   - **Return value:** `{family: sorted case ids whose caught is true}`. On the real 2A file this is `{"argon": ["A", "B", "C"], "grok": ["A", "B", "C"]}`.
4. `plant(source, case, dest)`: build the reviewed change in a fresh clone and return `Path(dest)`. Run every git command with `-c core.hooksPath=/dev/null`, `stdin=DEVNULL` and captured output. Steps:
   - `git clone -q --no-checkout <source> <dest>`, then `checkout -q --detach <commit>` and `remote remove origin`.
   - Count `old` in `<dest>/<file>`. If it does not occur exactly once, raise `ReplayError(f"case {id}: old text found {n} times")`. Otherwise write the file with `old` replaced by `new`.
   - Run `-c user.name=replay -c user.email=replay@invalid -c commit.gpgsign=false commit -q --amend --no-edit -a`.

   HEAD is then the task's own commit (same parent, subject and author) with the one planted line, so a reviewer sees a whole worker change. Any failed git command raises `ReplayError(f"case {id}: git {subcommand} failed")`. The source repository is only read.
5. `caught(provider, raw, case)`: `True` only when all of the following hold:
   - `observe_output.final_answer(provider, raw)` is a string;
   - `validate_verdict.extract_last_json_object` finds a verdict in it;
   - `validate_verdict.validate` against `schemas/review-verdict.schema.json` returns no errors;
   - `verdict == "FAIL"`;
   - some finding with `severity == "blocking"` has `text` containing both `Path(case["file"]).name` and one of `case["keywords"]`.

   Every other output is `False` (never raise for reviewer output).
6. Create `tests/test-replay-seeded-defects.py` (`class ReplaySeededDefectsTests(unittest.TestCase)`, the same import style as `tests/test-planning-stats.py`) with these methods:
   - `test_cases_and_required_set_match_2a`: the ids, commits, files and tasks. The real 2A required set. An unknown reviewer, a mismatched commit and an unknown case each raise `ReplayError`.
   - `test_plant_changes_one_line_of_the_task_commit`: for each case, cloned from the repository root:
     - `git diff --numstat <commit> HEAD` is `1<TAB>1<TAB><file>`;
     - HEAD~1 is `<commit>~1`, and the subject and author match the commit;
     - there is no remote and the tree is clean;
     - an absent old text raises `ReplayError`.
   - `test_caught_reads_only_a_failing_final_verdict_naming_file_and_defect`: a hit through each of the claude, agent, agy and codex final-answer shapes. No hit for each of: PASS, a non-blocking finding, the wrong file, no keyword, a schema-invalid object, no JSON, or a verdict that is not a final answer.
