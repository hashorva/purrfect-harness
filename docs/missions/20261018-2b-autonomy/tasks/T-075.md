## Objective

1. `scripts/usage_report.py`: add the option `--ledger-dir DIR`, default `<tasks-dir>/ledger`.
   - Input: every `*.json` in that directory, in sorted order, is a ledger row. An unreadable or non-object file is skipped.
   - Window: with `--since` or `--until`, a row counts only when `<tasks-dir>/receipts/<run_id>.json` exists and its `started_at` is in the window. Without a window, every row counts.
   - Group keys:
     - role: `role_tag`, or `untagged` when missing;
     - step: `task`;
     - seat: `<cli>.<tier>`, or `<cli>` when tier is null;
     - prompt version: `prompt_version`, or `unknown` when missing or null.
   - Each group entry is `{"key", "runs", "total", "without_cache", "unknown_runs"}`. `total` and `without_cache` sum observed values only. `unknown_runs` counts rows whose `tokens_total` is not observed. Lists are sorted by `total` descending, then by `key`.
   - The JSON output gains `harness`, with `by_role`, `by_step`, `by_seat` and `by_prompt_version`.
   - The table output, after the Front Desk line, gets one section per group: a blank line, a header such as `| role | runs | total | without cache | unknown |` (with `step`, `seat` or `prompt version` in place of `role`), the separator line and the rows.
2. Frozen, hand-written rows in `tests/fixtures/usage-report/ledger/`:
   - `a.json`: `{"run_id": "r-a", "task": "plan", "cli": "claude", "tier": null, "role_tag": "plan", "prompt_version": "scripts/brain_prompt.py:aaaaaaaaaaaa", "tokens_total": {"value": 1000, "source": "observed"}, "tokens_without_cache": {"value": 100, "source": "observed"}}`.
   - `b.json`: the same shape with `r-b`, `T-001`, `codex`, `economy`, `worker`, `scripts/spawn-worker.sh:bbbbbbbbbbbb`, 3000 and 300.
   - `c.json`: an old row with `r-c`, `T-001`, `cursor` and `economy`; both token fields are `{"value": null, "source": "unknown"}`, and it has no `role_tag` or `prompt_version`.
3. `tests/test-usage-report.py`: add `test_harness_runs_ranked_by_role_step_seat_and_prompt_version`. It checks the oracle's expected `harness` block, the empty block under a window, and the table rows. T-068's existing assertions stay.
