# Task: Per-provider token figures: total with cache reads, total without them, and the five parts, each formula proven by a real stream fixture (owner item 2, parser part)

Plan tags: category `metrics`, size `M`, review `argon` or `grok`. No dependency; runs in parallel with T-073 and T-076. No adapter argv change.
Owner item 2 (2026-10-19): every run records its total tokens including cache reads, its tokens without cache reads, and the parts (input, output, reasoning, cache read, cache write) as the provider reports them. Each provider has its own proven uncached formula; there is no shared one. A part or total that cannot be proven is `unknown`, never a guess. The numbers below come from real usage events in the saved logs under `.tasks/logs/`; the planner read them and kept only the usage event (no ids, text or paths). What they prove:
- Claude `input_tokens` 46 next to `cache_read_input_tokens` 1683716: input excludes cache reads, and the cache write is `cache_creation_input_tokens`.
- Codex `input_tokens` 637380 is larger than `cached_input_tokens` 605952: input includes cache reads.
- Cursor `inputTokens` 39280 is smaller than `cacheReadTokens` 233463: input excludes cache reads.
- agy `total_tokens` 3418 equals `input_tokens` 3216 + `output_tokens` 202, with `cache_read_tokens` 16873: input excludes cache reads, and the provider's own total includes neither cache reads nor `thinking_tokens`.

No stream proves whether reasoning sits inside output, so reasoning is recorded as a part and never added to a total.

## Objective

1. `scripts/observe_output.py`: add `TOKEN_FIGURE_FIELDS = ("input", "output", "reasoning", "cache_read", "cache_write", "total", "without_cache")` and `token_figures(provider, raw)`. It resolves `provider` through `ALIASES` (`agent` is cursor) and raises `ValueError` for an unknown provider, as `observe` does. It returns a dict with exactly those keys in that order, each value `observed(n)` or `unknown()`. `observe` and `stream_tokens` do not change.
   - claude (last `type: result` event, `usage`): input `input_tokens`; output `output_tokens`; reasoning `output_tokens_details.thinking_tokens`; cache_read `cache_read_input_tokens`; cache_write `cache_creation_input_tokens`. total = input + cache_read + cache_write + output; without_cache = input + cache_write + output.
   - codex (sum over every `turn.completed` event's `usage`; a value missing in any turn makes that part unknown): input `input_tokens`; output `output_tokens`; reasoning `reasoning_output_tokens`; cache_read `cached_input_tokens`; cache_write `cache_write_input_tokens`. total = input + output; without_cache = input - cache_read + output. Both totals stay unknown unless cache_write is observed 0 (no stream proves whether a cache write sits inside input) and cache_read <= input.
   - cursor (last `type: result` event, `usage`): input `inputTokens`; output `outputTokens`; reasoning always unknown; cache_read `cacheReadTokens`; cache_write `cacheWriteTokens`. total = input + cache_read + output; without_cache = input + output. Both totals stay unknown unless cache_write is observed 0.
   - agy (last `event: result` event, `result.usage`): input `input_tokens`; output `output_tokens`; reasoning `thinking_tokens`; cache_read `cache_read_tokens`; cache_write always unknown (agy reports none). total = input + cache_read + output; without_cache = input + output. Both totals are unknown when `total_tokens` is present and differs from input + output, because then the proof fails.
   - A total is unknown whenever one of its terms is unknown. Reasoning is never added to a total.
