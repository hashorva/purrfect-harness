## Objective

Implement the first, standalone half of F001: one schema-versioned immutable
`ExecutionSpec` persistence tool and one provider adapter used by both future brain and
worker integration. Do not integrate the spawn wrappers or receipts in this task; T-005
will do that only after this contract passes review.

The Phase 1 spec is intentionally small. It must require exactly these authorization
fields (additional fields fail validation):

- `schema_version: 1`
- UUID `run_id`
- non-empty `mission`, `work_unit`, `role`, `provider`, `model`, `effort`, `speed`,
  absolute `repo`, Git `base_commit`, and `prompt`
- `feature` is a non-empty string for `role: worker` and JSON `null` for `role: brain`
- positive integer `attempt`
- `role` is `brain|worker`; provider is `codex|claude|agent|agy`

Use `scripts/execution_spec.py` as the only schema-policy implementation and make it
importable by `scripts/execute_provider.py`. It must provide:

- deterministic construction/validation and exact-byte SHA-256
- atomic no-clobber persistence at `.tasks/specs/<run_id>.json`
- refusal to replace an existing `run_id`, even with identical bytes
- a new `run_id` for every amendment
- no external Python dependency

Persist validated canonical JSON bytes before any launch. A failed field, extra field,
unsafe repo value, non-Git base commit, invalid UUID, or existing run ID must leave no
partial final spec and must not invoke a provider sentinel.

Use `scripts/execute_provider.py` as the only provider grammar. It reads and validates a
persisted spec, translates it to an argv list plus an empty explicit environment-override
map, supports a JSON dry-run for exact contract tests, and launches without `eval`.
Provider mapping is fixed to the installed CLI contracts:

- Codex: `codex exec -C REPO -s workspace-write -m MODEL -c
  model_reasoning_effort="EFFORT" PROMPT`; effort `low|medium|high|xhigh`, speed must
  be `unknown`.
- Claude: `claude -p PROMPT --model MODEL --effort EFFORT --allowedTools
  Read,Write,Edit,Bash`; effort `low|medium|high|xhigh|max`, speed must be `unknown`.
  The prompt must precede variadic `--allowedTools`.
- agy: `agy --dangerously-skip-permissions --print-timeout 30m --model MODEL --effort
  EFFORT -p PROMPT`; effort `low|medium|high`, speed must be `unknown`; `-p` and its
  prompt remain last.
- agent: `agent -p --force --trust --workspace REPO --model RESOLVED_MODEL PROMPT`.
  For requested effort `low|medium|high|xhigh` and speed `standard|fast`, encode explicit
  bracket parameters `effort=<value>,fast=false|true` in an otherwise unparameterized
  model ID. Reject already-parameterized model IDs and `unknown` for either field rather
  than guessing how to merge or inherit them.

For Codex/Claude/agy, reject every non-`unknown` speed before launch. Never silently
downgrade an unsupported effort/speed. Dry-run resolution must record observed model,
effort, and speed as `unknown`; provider output has not confirmed them yet. It must not
guess observation from the requested model string.

Add focused deterministic tests and mount them from `tests/run-tests.sh`. Exact argv and
explicit env-override tests cover every provider for both `brain` and `worker` specs.
Negative tests must invoke the real shared adapter with a provider sentinel and prove the
sentinel remains untouched for a missing required field, unsupported effort, unsupported
speed, and overwritten run ID. Remove/bypass each new guard in turn, observe its mounted
test fail, then restore it before completion.

Add the new scripts and schema to both manifest install and update ownership so a consumer
receives the complete adapter contract. Do not change release/version semantics.
